# 知页 · Pagewise 菜单名称与图标规范

版本1.0。13项原始菜单对应13组图标，另附“搜索书籍”变体，共14个基础图标。图标为原创SVG路径，统一24×24坐标，黑白呈现，透明背景。当前是设计与可复用资源交付，尚未替换现有应用。

## 菜单名称与含义

|原名称|建议名称|图标隐喻|用途与边界|
|---|---|---|---|
|藏书|书库|三册书脊|全部书籍和书单入口，外部书目与本地文件以状态区分。|
|在读|在读|展开的书页|正在阅读的书和继续阅读入口；按钮文案使用“继续阅读”。|
|笔记|笔记|带装订线的笔记本|跨书汇总笔记；可按书籍、标签或时间筛选。|
|阅读记录|阅读记录|回转箭头与时钟|阅读时段、完成历史和阅读统计；若只展示最近打开清单，则命名“最近阅读”。|
|设置|设置|齿轮|账号、数据、设备及全局默认值；本书排版留在阅读器内。|
|目录|目录|分级条目列表|本书章节结构与定位；面板可展示二级、三级标题。|
|划线想法|批注|标记笔与下划线|本书的划线和附着原文的想法；面板内使用“划线”“想法”筛选。|
|书签|书签|书签带|菜单打开本书书签列表；当前页添加与移除书签是独立动作。|
|听书|朗读|耳机与文字|当前电子书的文字转语音。以后接入专业有声书时，可单独设置“听书”。|
|ai助手|阅读助手|对话气泡与四角光点|解释、问答、总结与内容分析；面板标题可标明“阅读助手 · AI”。|
|书类搜索|书内搜索|书页与放大镜|按阅读场景理解原名称，搜索当前书全文；书库搜书另用search-library。|
|阅读模式|阅读模式|双栏阅读页面|翻页、滚动、单双栏和专注等阅读方式；工具栏短标签为“模式”。|
|排版|排版|字母A与排版行|字体、字号、字重、行段距、字距、边距与对齐；面板标题为“排版设置”。|

“书类搜索”按阅读场景暂理解为“书内搜索”。如果原意是在书库按书名、作者、标签查找，则使用额外提供的“搜索书籍 / search-library”。不把一个含糊名称同时用于两个搜索范围。

保留清楚的常用名称，不强求全部两个字。“在读”适合作为页面名称，“继续阅读”适合作为执行动作。“阅读记录”若包含完成历史、阅读时段与统计就保留；只有最近打开列表时改叫“最近阅读”。

“笔记”是跨书入口，“批注”是当前书的划线与想法，“书签”仅保存位置；三者使用不同图形并保留文字。“朗读”对应当前EPUB文字转语音；专业有声书可另设“听书”。“阅读助手”涵盖提问、解释、总结，面板显式说明AI。“阅读模式”工具栏可简写“模式”，负责翻页、滚动、单双栏与专注等方式；“排版”负责字体和页面参数。

## 信息层级

主导航：书库、在读、笔记。阅读记录和设置作为次级入口，不增加到主导航造成重复。

阅读工具使用两行四列的稳定布局：

|第一行|第二项|第三项|第四项|
|---|---|---|---|
|目录|书内搜索|批注|书签|
|朗读|阅读助手|模式|排版|

长标签保留完整文字或使用明确面板标题，按真实可用宽度验证。阅读器中央点按打开工具面板，图标与文字同时出现；正常阅读时隐藏工具面板。

## 视觉与状态

- 图标坐标24×24；常规线宽2，强调线宽2.25；圆端点与圆连接。
- 主导航与阅读工具建议以28 CSS px起步；提供24与32尺寸预览。不要把图标尺寸当作触区尺寸。
- 触区至少48×48 CSS px，并按实际显示密度、缩放与物理标尺检查约9–10 mm的目标尺寸。这是本方案设计目标，不是设备实测结果或规范符合性声明。
- 常规与选中均使用黑色。选中同时加粗标签、显示底部黑色短线或实边框；不能仅靠线宽变化区分。
- SVG使用currentColor，支持在黑底上改成白色；不使用阴影、渐变、磨砂、微弱灰线和循环动画。
- 状态通过父按钮表达：导航用aria-current，展开面板用aria-expanded，可切换动作用aria-pressed。图标已有文字标签时使用装饰性SVG，避免屏幕阅读器重复朗读。
- “书签”菜单打开列表；“添加书签/移除书签”是独立动作。填充书签图标只表示当前页已加书签，不表示列表面板当前打开。

## 交付文件

- svg/outline：14个常规透明SVG。
- svg/emphasis：14个强调透明SVG。
- svg/actions/bookmark-marked.svg：当前页已加入书签状态。
- pagewise-icons.sprite.svg：SVG symbol合集。
- components：Vue 3图标组件及类型映射；需要按现有项目目录接入。
- menu-manifest.json：名称、分组、语义和视觉参数。
- preview.html：不依赖外部脚本的交互预览，可切换尺寸与状态。
- Pagewise_icons_overview.png：图标设计总览。
- Pagewise_icons_sizes.png：24、28、32像素与触区示意。

## Vue使用示例

```vue
<button aria-label="书库" aria-current="page" class="nav-item selected">
  <PagewiseIcon name="library" :size="28" emphasis />
  <span>书库</span>
</button>

<button :aria-expanded="tocOpen" aria-controls="book-toc">
  <PagewiseIcon name="table-of-contents" :emphasis="tocOpen" />
  <span>目录</span>
</button>

<button :aria-pressed="bookmarked" :aria-label="bookmarked ? '移除书签' : '添加书签'">
  <PagewiseIcon name="bookmarks" :marked="bookmarked" />
</button>
```

资源已进行XML和栅格预览检查。24/28/32为屏幕像素层面的设计检查，不能替代NoteX3 Pro真机的触区、残影、对比度与辨识试用。

## SVG symbol引用示例

```html
<svg viewBox="0 0 24 24" width="28" height="28" fill="none"
     stroke="currentColor" stroke-width="2" stroke-linecap="round"
     stroke-linejoin="round" aria-hidden="true">
  <use href="/pagewise-icons.sprite.svg#pw-library"></use>
</svg>
```

通过应用静态资源服务器提供sprite文件；离线直接打开HTML预览使用内联图形，不依赖外部sprite引用。
