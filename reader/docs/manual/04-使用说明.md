# 四、使用说明

本篇汇总知页（Pagewise）v2.5.0 在 **BOOX Android 墨水屏** 与阅读工作流中的核心操作：入库与监控文件夹、三模式书架与分类著录、AI 服务与划词查词、PDF 精读、阅读统计、本地备份与设置恢复。

---

## 1. 导入书籍与监控文件夹

### 支持格式

| 类别 | 格式 | 说明 |
|---|---|---|
| 流式电子书 | EPUB、MOBI、AZW、AZW3、FB2、.fbz | 原生解析排版与内嵌目录 |
| 纯文本与标记 | TXT、HTML / XHTML、Markdown（.md） | 自动按结构分章并适配纸墨排版 |
| 漫画压缩包 | CBZ、CBR | 按图页连续翻阅（不含流式重排） |
| 版式文档 | PDF | 支持 MuPDF / PDFium 双渲染与 Wacom 手写 |

> 不支持带 DRM 加密的文件；已于 v2.5 精简退役历史格式（如 DjVu）。

### 入库方式

- **本地导入**：「藏书」页点击「**导入**」通过系统文件选择器单选或多选入库。
- **系统分享 / 打开方式**：在其他应用点击电子书或 PDF 选择「使用知页打开」，文件会安全写入应用主数据目录并自动入库。
- **SAF 监控文件夹**：「设置 → 文件夹与扫描 → 选择/重新授权」授予一个本地书库目录权限。该目录下的书籍不额外占用复制空间；**仅在切回前台超过 60 秒或手动点击「重新扫描」时执行检查**，不在后台高频率轮询耗电。

## 2. 三模式书架与馆藏管理

知页 Android 原生层提供 **「藏书」「正在阅读」「全部笔记」「阅读统计」「设置」** 五个一级底部入口：

- **三模式藏书**：支持按馆藏类别、阅读状态与搜索词筛选；支持列表视图与三列/四列封面网格视图切换；支持多选「**管理**」批量修改阅读状态、标签、置顶或移出。
- **在读队列**：聚焦正在阅读/想读/暂缓/已读/弃读，直接展示书脊式进度规（Fore-edge Gauge）、累计阅读时长与推荐阅读。
- **安全删除保护**：由 SAF 监控文件夹关联的书目受到源关联保护，防止误删后重扫恢复错位；若原文件移动位置，可使用「**重新关联文件**」无损绑定回同一书目，完整保留笔记和进度。

---

## 3. 书籍详情、双层元数据与十类馆藏索书号

打开任意书籍卡片的详情页，可在「概览信息」「目录结构」「笔记与标注」「相关与拓展」间切换：

- **双层著录元数据补全**：在概览中点击「**补全元数据**」，可先发起**第一级**公开书目并发检索（OpenLibrary / Google Books / 豆瓣等候选列表由你点选采纳，不擅自覆盖已有内容），也可使用**第二级**自有 AI 推理结构化补全。
- **馆藏十类归档与锁定**：支持 10 类基础分类索书号、`#主题`、特征标签与细粒度属性，并可逐项勾选「锁定」防止后续自动分类覆盖。
- **前情提要（Catch-up）**：久未翻开的书点「前情提要」，汇总当前进度、闲置天数、本书简介与最近 5 条核心批注并一键继续阅读。

---

## 4. 笔记管理、导出与原文深链

在「**全部笔记**」页或书籍详情的「**笔记与标注**」页签中：

- 支持按**全部 / 想法 / 标注 / 书签**筛选及关键字搜索，每条高亮以墨水屏四类语义标签（重点、概念、核心、存疑）区分；
- 点击「**回到原文**」会携带精确锚点（`?loc=...`）直接拉起 EPUB 或 PDF 阅读页并定位至该段落/页码；
- 「**导出读书笔记**」与「**跨书对比预览**」会自动聚合当前检索范围下最多 500 条全部记录（不局限于单页 30 条），支持一键 **复制 Markdown** 或调起 Android 系统分享；
- **草稿安全屏障**：编辑想法期间每 600ms–1.2s 自动存为本机草稿，未提交前切走或异常关闭不会丢失。

---

## 5. 阅读页通用工具与系统词典

- **目录与书内搜索**：无内置目录的 TXT/EPUB 自动从正文结构生成章节；搜索支持多词、大小写与正则筛选，点击结果跳转到对应页后底栏常驻「**回到刚才位置**」。
- **查词（BOOX / Android 系统词典）**：长按选词后在弹出工具栏点击「**查词**」，通过系统文本操作 Intent 拉起设备预装的 BOOX 词典、欧路词典等（若设备未安装兼容词典，会友好提示而不会静默无反应）。
- **AI 服务（自有密钥）**：知页不提供内置云代理或免费公共额度。需在「**设置 → AI 服务**」选择 DeepSeek、OpenAI、Google Gemini、OpenRouter 等服务商并填写你自己的 API Key 与模型，可通过「**测试连接**」验证。在墨水屏开启时，AI 流式回复会聚合为短批并用 A2 模式低闪烁输出，生成结束后恢复 Regal 清刷。

## 6. PDF 阅读

知页针对平板 PDF 阅读提供完整手势、双栏适配与工具协同：

- **视图控制**：切换 MuPDF / PDFium 渲染器、单页/对页/书籍对页、连续滚动或单页翻页、适合高度/适合宽度；点击屏幕中央呼出/隐藏顶部工具栏并配合底部进度滑块极速预览。
- **批注与草稿安全**：选中文本后可选择颜色立即高亮，或点「**写想法**」确认后再落库（避免取消时留下空白高亮）；触控设备上每条批注卡片常驻大尺寸删除/编辑/跳转按钮。
- **分屏伴读与 AI 助手**：宽屏（`>820dp`）下打开 PDF AI 阅读助手会采用非遮挡分屏并列展示，且**翻页时保留对话与分析结果不自动关闭**。
- **原笔迹 Wacom 手写**：支持压感笔迹、防掌触、笔杆按键擦除及区域局部刷新。

## 7. 墨水屏硬件控制与休眠封面

在「**设置 → 墨水屏与硬件**」中可集中管理 BOOX 设备特性：

| 控制项 | 说明 |
|---|---|
| **EPD 全屏清残影间隔** | 设置每翻 N 页执行一次 GC16 全屏刷新（支持 0/跟随系统、5、10、15、20、30 页），亦可点击「**立即全屏清残影**」手动消除灰阶残影 |
| **冷暖双色温前光** | 支持总开关、「日间清透 / 夜间暖光」预设以及对称的 `冷光 −10% / +10%`、`暖光 −10% / +10%` 步进微调 |
| **系统休眠封面（屏保）** | 可在阅读器中生成当前在读书籍封面与进度的灰度高分辨率 PNG，自动导出到系统相册 `Pictures/Screensaver/` 供 BOOX 系统设为锁屏壁纸 |

---

## 8. 阅读统计与计时原则

- 「**阅读统计**」展示今日时长、连续阅读、本周打卡条、周/月/年趋势柱图、年内热力图（窄屏支持切换 **上半年 / 下半年 / 自适应**，点击格子直达当天书目排行）及增强月历（区分**已达标 / 活跃≥60s / 今日框线 / 未满**）。
- **计时机制**（可在统计页点「**如何计时**」查看）：仅在前台活跃浏览时计时；静态停滞超过闲置上限会停止计时并在复读时续接。

---

## 9. 数据安全、备份与设置恢复

- 知页为全本地存储架构，**无远程账号同步、无 WebDAV 中转与云端上传**；请勿轻信任何非本地托管的同步提示。
- 在「**设置 → 文件与数据**」导出 `.okf.zip` 整库备份包，更换设备或重装前请将其保存在应用目录之外（例如 `Downloads`）；导入时会先预览文件大小并经事务校验确认。
- 在各界面遇到意外提交中断或未保存排版草稿时，点击顶栏「**核对恢复**」图标即可检查未决提交并安全选择重试或放弃，不盲目重发网络请求或覆盖较新状态。
