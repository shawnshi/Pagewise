# 轻阅使用手册

**轻阅（LightRead）** 是一款开源、本地优先的电子书与论文阅读器。藏书、论文、阅读进度和批注默认保存在你自己的设备上；不用注册账号，本地阅读不需要联网。找书、在线听书、AI、同步这些联网功能都是可选的，用不用由你决定。

## 能在哪些设备上用

| 版本 | 说明 |
|---|---|
| **桌面版** | Windows、macOS（Apple 芯片 / Intel）、Linux（deb / rpm / AppImage）。功能最完整：本地离线语音、Calibre 书库、论文 Agent、自定义存储位置、文件关联等只在桌面版提供 |
| **网页版** | 在浏览器中使用，可安装为 PWA。数据保存在当前浏览器里；听书只能用系统语音，部分书源需要配置代理 |
| **Android 版** | **实验版本**，仅 arm64。支持阅读、在线听书和同步，界面仍在持续适配 |

下载与安装步骤见项目 [README](../../README.md#下载与安装)。

## 三分钟上手

1. 打开轻阅，在「**藏书**」点「导入书籍」，或把书拖进窗口。
2. 点封面开始阅读。点屏幕左右两侧翻页，点**中间**呼出工具栏。
3. 在工具栏的「排版」里调字号和主题；在「模式」（电脑上是「阅读模式」按钮）里试试夜读、大字、打字机或歌词，也可以打开点睛阅读；在「听书」里让轻阅读给你听，在「背景音」里放一点雨声。
4. 想在手机和电脑间接着读，到「**设置 → 账号与同步**」登录轻阅账号或连接网盘。
