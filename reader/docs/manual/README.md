# 知页（Pagewise）使用手册

**知页（Pagewise）** 是一款本地优先（Local-First）的电子书与论文阅读器，面向 **BOOX / Onyx 墨水屏平板与手机**（Android arm64）以及桌面阅读环境打造。书库、阅读进度、批注、Wacom 手写笔记与阅读统计全部存储在本地，无需注册账号，本地阅读与基础整理不联网。

## 支持平台与设备能力

| 平台 | 核心能力与说明 |
|---|---|
| **Android 墨水屏版（BOOX 原生）** | 原生书库、正在阅读、笔记、统计、设置与本手册；支持 BOOX EPD 波形（Regal / A2 / DU / GC16）、冷暖双色温前光、Wacom 电磁笔手写批注、实体音量键/蓝牙翻页、SAF 监控文件夹自动入库与离线休眠封面生成 |
| **流式电子书引擎** | 支持 EPUB、MOBI、AZW、AZW3、FB2、FB2.zip（.fbz）、TXT、HTML、Markdown（.md）、CBZ、CBR；内置纸面排版、护眼/墨水屏/打字机/歌词、AI 伴读与系统词典查词 |
| **PDF 精读引擎** | 支持 MuPDF / PDFium 双渲染器，单页 / 对页 / 书籍对页与连续滚动，划线、写想法、AI 解读、书内搜索、目录与原笔迹手写叠加层 |

## 三分钟上手

1. 打开知页，在「**藏书**」页点击右上角「**导入**」按钮，或打开「**设置 → 文件夹与扫描**」授权一个本地监控文件夹。
2. 点击任意书封开始阅读：点屏幕左/右三分之一翻页，点屏幕**中间三分之一**呼出顶部与底部工具栏；支持手机单手模式或 BOOX 物理音量键翻页。
3. 在阅读页工具栏中：
   - 点「**排版**」调整字号、行高、页边距与墨水屏黑白主题；
   - 点「**阅读模式**」开启墨水屏刷新优化、打字机或**伴读**；
   - 点「**手写**」（Wacom 墨水屏）直接在书页批注，使用笔杆侧键擦除。
4. 回到「**全部笔记**」或「**阅读统计**」导出 Markdown 笔记，或查看周/月/年热力图与每日阅读目标。

> 本手册对应 **知页（Pagewise）v2.5.0**。应用内离线入口：「设置 → 关于与帮助 → 使用手册」。
