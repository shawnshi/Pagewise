# 三、声音：朗读

这一篇讲朗读：在知页里将书页合成为语音，实时高亮正在朗读的句子、自动翻页，支持定时关闭、断点续听与系统媒体控制。

> 本篇以**流式电子书阅读页**（EPUB、MOBI、AZW3、FB2、TXT、Markdown 等）为主。PDF 朗读的控制差异见文末「[PDF 朗读有什么不同](#pdf-朗读有什么不同)」。

---

## 1. 开始朗读

- 大屏：阅读页顶栏点击「**朗读**」耳机按钮；
- 窄屏：点屏幕中间呼出工具栏，在底栏点击「**朗读**」；
- 从任意位置起听：长按选中正文后，在弹出选区工具栏点击「**从这里听**」。

开始后，正在朗读的句子会高对比标注；读完当前页自动翻页、跨章衔接；全书结束时提示读完。固定版式漫画类书籍暂不支持全文提取朗读。

---

## 2. 播放控制与语速

控制条提供：**上一段 · 上一句 · 播放/暂停 · 下一句 · 下一段** 以及 `0.5x–2.0x` 语速调节（每档 `0.1x`）。切换语速或音色会在当前句/段结束后自然生效，无需中断重试。

> 收起面板后朗读继续进行，页面顶部留存轻量控制胶囊（拖动可固定位置，双击归位）。

---

## 3. 朗读时自由翻页浏览

朗读过程中可以正常翻页、打开目录或查看笔记，朗读不会把页面强行拉回。面板与胶囊提供：

| 按钮 | 作用 |
|---|---|
| **回到朗读位置** | 立即跳回当前发声句子所在页 |
| **从这页开始听** | 将朗读指针重置为你当前停留在的页面 |

---

## 4. 定时关闭与断点续听

| 功能 | 说明 |
|---|---|
| **定时关闭** | 支持关闭、`15 / 30 / 60 / 90 分钟` 后暂停，或「听完本章」后暂停 |
| **断点续听** | 每次停止时自动记录句级锚点，下次打开朗读面板可一键「继续听」 |

---

## 5. 硬件按键与媒体会话冲突处理

在 Android 上朗读运行时，知页会注册系统 `MediaSession`（包含 `播放/暂停`、`下一句/上一句` 等动作），以便锁屏界面与蓝牙耳机线控操作：

- **音量键保护**：朗读活跃播放期间，设备物理音量键（`音量 +` / `音量 −`）自动交还系统控制音量大小；暂停或停止朗读后，恢复作为阅读器翻页键；
- **蓝牙配件键**：朗读运行时蓝牙耳机 `下一曲 / 上一曲` 用于跳段；未在朗读时可用于蓝牙翻页器翻页。

---

## 6. 选择声音：Android 与桌面可用引擎

| 引擎 | 需要联网 | 可用平台 | 说明 |
|---|---|---|---|
| **在线模型** | 是 | Android、桌面 | 神经网络高自然度音色（默认推荐，断网时自动提示回退至系统语音） |
| **系统语音** | 否 | 全平台 | 调用 Android / 系统内置 TTS 引擎（离线可用，音质由设备安装语音包决定） |
| **本地模型** | 否 | 仅桌面版 | 桌面端 Kokoro 本地算力合成；Android 版精简包不含桌面大体积离线语音，以免占用墨水屏存储空间 |

---

## PDF 朗读有什么不同

PDF 阅读页顶部工具栏「**朗读**」提供专属轻量控制条，并已补齐核心阅读闭环：

| 功能 | 流式电子书 | PDF 阅读页 |
|---|---|---|
| 开始 / 暂停 / 停止 / 语速调节 | ✓ | ✓ |
| 音色与引擎切换 | ✓ | ✓ |
| 起听位置 | 本页、断点或选中文字 | 从当前页起始，或选中文字后点击「**从这里听**」 |
| 定时关闭 | 15 / 30 / 60 / 90 分钟或本章末 | 支持 15 / 30 / 45 / 60 分钟睡眠定时 |
| 句子级高亮与跳句 | ✓ | 按页推进并自动翻页（仅文字层 PDF） |
| 纯扫描版 PDF | — | 无文字层，无法提取朗读 |
