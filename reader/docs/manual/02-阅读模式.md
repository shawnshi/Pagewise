# 二、阅读模式与阅读界面

这一篇讲两件事：

1. **阅读模式**：书页怎么动、怎么带你读。顶部是**点睛阅读**（基础版 / 智能版），下面分两组：
   - **场景**：夜读、护眼、墨水屏、大字、沉浸——一键套用一组设置，再点一次恢复原样；
   - **带读**：自动翻页（滚动方式下叫自动滚动）、打字机、歌词、听书（同一时间只运行一个）。
2. **排版**：书页长什么样。字号、字体、主题、调暗、翻页 / 滚动、分栏、进度显示等所有具体数值都只在这里调（见第 8 节）。

> 本篇说的是 EPUB、MOBI、AZW3、FB2、TXT、HTML、Markdown 等**流式电子书**的阅读页。PDF 和论文有单独的阅读页，见 [04-使用说明](04-使用说明.md#6-pdf-与论文阅读)。点睛阅读单独成篇，见 [05-点睛阅读](05-点睛阅读.md)；听书和背景音见 [03-声音](03-声音.md)。

---

## 1. 打开「阅读模式」面板

| 设备 | 入口 |
|---|---|
| 电脑（窗口较宽时） | 阅读页**顶栏**的「阅读模式」图标按钮 |
| 手机（或窗口宽度 ≤ 600px） | 点屏幕中间呼出工具栏，**底栏**的「模式」 |
| 键盘 | 按 **M** |

电脑上面板浮在顶栏下方，手机上是从底部弹出的抽屉，点遮罩即可收起。同一时间只能打开一个面板，打开「阅读模式」会自动收起目录、排版等其他面板。有模式在运行时，入口按钮会高亮。

面板从上到下依次是：

1. **点睛阅读**：总开关，打开后选「基础 / 智能」（见 [05-点睛阅读](05-点睛阅读.md)）；
2. 打字机或歌词运行时，显示**读到哪、还要多久**（见 [5.2.4](#524-进度与剩余时间)）；
3. **场景**：五张开关卡片；
4. **带读**：四个分段「自动翻页 / 打字机 / 歌词 / 听书」，正在运行的那个会有标记。

每个场景都是一张卡片：

- 点卡片本身就是**开 / 关**，卡片上写着「已开」或「关」。刚打开的场景会顺带展开它的详情。
- 点卡片角上的 **ⓘ**（「说明与设置」），可以先看这个场景**会调整什么**、它自己有哪些选项，不用开也能看。
- 夜读、护眼、大字的详情里有「**在排版里微调**」，点一下打开排版面板，直接定位到对应的分区。场景本身不另存一份字号、主题之类的数值，具体数值一律在排版里调。

## 2. 关掉场景时，原来的设置会回来

夜读、护眼、墨水屏、大字和带读里的歌词，都是在你现有的排版上「临时换一套」：开启时轻阅先**记下被改动的那几项原来的值**，关闭时再把它们**写回去**。所以可以放心试，关掉就回到开之前的样子。

- **叠着开也没关系**：比如先开大字、再开歌词（歌词会把字号再放大），关歌词回到大字的字号，再关大字回到最初的字号。
- **开着场景时在排版里调过的数值会被记住**：比如开着大字时在排版里把字号从 24 改成 26，关闭大字后字号回到原来的值，下次再开大字时用的是 26。
- **开着场景时在排版里直接换了主题**（比如开着夜读时点了米黄），轻阅就认为你另有选择，关闭时不再改回去。
- 大字、墨水屏、沉浸开着时，排版面板顶部会提示「场景开启中」，点「管理」回到这里关闭。

## 3. 场景

### 3.1 夜读

把正文换成**夜间主题**（深灰底、浅色字）；关闭后回到之前的主题。如果之前用的是「跟随外观」而应用外观本身就是深色，关闭夜读会改成白色主题。

**定时开启**（点 ⓘ 展开）：

- 打开「定时开启」，设定「从」「到」的时间，默认 **22:00 到 07:00**，可以跨午夜。
- 阅读页开着时，到了开始时间会自动切到夜间，到了结束时间切回去（一分钟之内生效）。
- 只有**定时打开的夜读**才会被定时关掉；你自己手动开的不会被关。在时间段内手动关掉，也不会被反复改回来。

> 在排版里选「夜间」主题，或者选「跟随外观」而应用外观是深色，夜读卡片都会显示「已开」。嫌夜里屏幕太亮，用排版「配色」里的**调暗**。

### 3.2 护眼

护眼做两件事：

| 内容 | 说明 |
|---|---|
| **暖色主题** | 用你在排版里最后选的暖色主题：米黄（默认）或护眼绿 |
| **休息提醒** | 默认开，连续阅读 **20 分钟**（可选 20 / 30 / 45 分钟）后提醒你休息一下 |

**休息提醒是什么样的**：屏幕上出现一条轻提示「看看 6 米外，休息 20 秒」，附 20 秒倒计时，有三个按钮——「休息好了」「跳过」「30 分钟内不再提醒」。提醒出现时，打字机、歌词会**自动暂停**，自动翻页会停止。

- 「连续阅读」的算法和阅读记录一样：翻页、轻点、带读推进都算在读；中间停下超过 5 分钟就算中断，重新计时。
- 「休息好了」和「跳过」都从现在重新计时。

> 说实话：护眼只是换了暖色底，再加一个休息提醒。它**不能过滤蓝光**，也不承诺「保护视力」。真正有帮助的是按时让眼睛休息、看看远处——提醒就是为这个准备的。

在排版里直接选米黄或护眼绿，也算开启了护眼（卡片显示「已开」，休息提醒同样生效）。想让屏幕暗一些，用排版「配色」里的**调暗**（对所有主题生效）。

### 3.3 墨水屏

适合墨水屏阅读器、墨水屏手机等设备：

- 正文改为**纯黑白高对比**，文字稍微加粗；夜间配合时是黑底白字。
- **去掉翻页动画**和各种过渡效果，减少残影。
- 打字机最少**按句**显示（逐字在墨水屏上残影严重）；关闭墨水屏后恢复你原来的粒度。
- 歌词改为**整屏跳**：当前行快到屏幕底部时一次性跳回上方，而不是平滑滚动。
- 点睛阅读的标记改用**线型**区分（实线、点线、双线），不靠颜色。

轻阅识别出像是墨水屏设备时，会在阅读页提示一次「看起来这是墨水屏设备，要开启墨水屏模式吗？」，点「墨水屏」开启，或点「关闭」不再提示。不会自动替你开启。

### 3.4 大字

给长辈和想要大字号的读者准备的一键场景：

| 档位 | 字号 |
|---|---|
| **大**（默认） | 24px |
| **特大** | 30px |

同时会：行距 **2.0**、字距 **0.05em**、字体换成**黑体**、改为左对齐、页边距略收窄、段落之间多留一点空、正文稍微加粗；**强制单栏**；工具栏按钮放大，更好点。

关闭后恢复原来的排版。开着大字时在排版里调过的字号会被记住，下次开启时沿用（见第 2 节）。

### 3.5 沉浸

只留下正文：

- 页眉不再显示**章名**，页脚不再显示**本章剩余页数**；再打开「**隐藏页码**」，页脚整条都留空。
- 开启时工具栏立即收起；之后工具栏只在**轻点屏幕中间**时出现，鼠标移到窗口边缘不会再把它呼出来。
- **Android**：同时**隐藏系统状态栏和导航栏**（从屏幕边缘滑动可以临时呼出），并**保持屏幕常亮**。
- **电脑和网页版**：在浏览器支持的情况下（Screen Wake Lock），阅读时保持屏幕不自动熄灭；不支持的环境里这一项不起作用，其他效果照常。

> 沉浸不会屏蔽系统通知，需要免打扰请在系统里设置。

## 4. 「排版」和「模式」怎么分工

- **排版**管「书页长什么样」：每个数值（字号、行距、主题、调暗、翻页 / 滚动、分栏……）只有这一个地方能调。
- **模式**管「书页怎么动、怎么带你读」：带读、点睛阅读，以及把一组排版值打包的**场景**。
- 两边不重复：双栏只在「排版 → 分栏」里；护眼的底色就是排版里选的暖色主题；调暗在「排版 → 配色」。

## 5. 带读：自动翻页、打字机、歌词、听书

这四种方式都是让书「自己往前走」，原则上**同一时间只运行一个**：开始打字机或歌词时，会停掉正在运行的其他带读。唯一的例外是**歌词可以跟着听书走**，见 [5.3](#53-歌词)。具体规则见 [5.5](#55-带读之间的关系)。

### 5.1 自动翻页

每隔设定的秒数自动翻到下一页，适合双手不方便、或想保持匀速阅读的时候。

1. 在「带读」里选「自动翻页」。
2. 拖动「速度」滑块，范围 **3–60 秒/页**（默认 15 秒/页），调整后立即按新速度继续。
3. 点「开始」；再点「暂停」停下。

翻到全书最后会自动停止；按 **Esc** 也会停止。

### 5.2 打字机

打字机模式会把**当前页**的文字隐藏起来，再按你设定的速度一个字一个字（或一句一句、一行一行）地「打」出来。读过的文字始终可见，打完一页会稍作停留再自动翻页。

它的作用是**用节奏帮你进入状态**、减少走神，并不承诺让你读得更快——面板上也是这么写的。

#### 5.2.1 开始与退出

1. 在「带读」里选「打字机」，按需调整下面的选项。
2. 点「**从本页开始**」。面板会自动收起，文字从当前页开头开始出现。
3. 想结束时，打开面板点「**退出打字机**」，或按 **Shift+T** / **Esc**。

> 也可以不开面板，直接按 **Shift+T** 开始或退出。

#### 5.2.2 选项说明

| 选项 | 可选值 | 说明 |
|---|---|---|
| **粒度** | 逐字 / 逐句 / 逐行 | 文字出现的单位。默认「逐字」；逐句、逐行画面跳动更少 |
| **速度** | 中文 60–1200 字/分；西文 40–800 词/分 | 默认中文 300 字/分、西文 200 词/分。单位按书的语言自动切换。和歌词的「自动」推进共用 |
| **快捷档** | 慢 / 中 / 快 | 中文书为 200 / 300 / 450 字/分；西文书为 150 / 200 / 300 词/分 |
| **后文** | 隐藏 / 淡显 | 还没「打到」的文字是完全隐藏，还是用很淡的颜色先显示出来 |
| **标点停顿** | 开 / 关 | 遇到句号、逗号等标点时稍作停顿，更接近自然阅读节奏（默认开） |
| **墨迹未干** | 开 / 关 | 刚出现的几个字用强调色显示，帮助视线跟上（默认开） |
| **打字声** | 开 / 关 | 出字时播放轻微的打字声（默认关）。速度超过 600 字/分时每 3 个字响一次；听书进行中时不发声 |

**调速度的三种方法**

- 拖动滑块，或点两侧的「减速」「加速」按钮（每次约 ±10%）。
- 点「慢 / 中 / 快」快捷档。
- **直接输入数字**：在滑块右边的数字框里输入想要的速度，按回车或点别处生效。超出范围时会自动收到最接近的有效值，并在框里显示实际生效的数字。

#### 5.2.3 运行中的操作

| 想做什么 | 怎么做 |
|---|---|
| 暂停 / 继续 | **轻点正文任意位置**（打字机运行时轻点不会翻页，防止误触）；或按 **空格**；或点底部迷你控制条的按钮 |
| 当前段直接显示完 | 按 **→** |
| 重新打当前这句 | 按 **←** |
| 加速 / 减速 | **Shift+↑** / **Shift+↓**，或迷你控制条上的 − / + |
| 退出 | **Esc**、**Shift+T**，或迷你控制条上的退出按钮 |
| 想仔细看某句 | 长按选中文字：打字机会暂停，并把进度推进到你选中的地方 |

**底部迷你控制条**：打字机运行时，屏幕底部居中会出现一条小控制条，显示状态（打字中 / 已暂停 / 即将翻页）、当前速度和本章大约还要多久，以及暂停、减速、加速、退出按钮。运行 3 秒后它会自动淡出，暂停时一直显示；呼出工具栏时它会让到底栏上方。

**会自动暂停的情况**：打开任何面板（目录、排版、阅读模式、背景音等）、弹出点睛卡片或休息提醒、切到其他应用或窗口进入后台时，打字机都会自动暂停，回来后点一下即可继续。

#### 5.2.4 进度与剩余时间

打字机或歌词（自动推进）运行时，再打开「阅读模式」面板，顶部会显示：

- 当前章名和本章进度条；
- **本章还剩约多久**；
- **预计几点读完**本章（跨过午夜会显示「预计明天 …」）；
- **全书百分比**和全书大约还剩多久。

这些时间是按你设定的速度估算的（开了「标点停顿」会多留一点余量），并随时间自动刷新。迷你控制条上也会显示「本章约 N 分钟」。

#### 5.2.5 其他说明

- **不支持固定版式的书**：漫画、按页排版的 EPUB 等会提示「固定版式的书暂不支持打字机模式」。PDF 也没有打字机模式。
- **系统开启了「减少动态效果」**：面板会提示建议使用逐句显示，翻页前也会多停一会儿；第一次使用时默认粒度会自动改为「逐句」。
- **阅读时长照常记录**：打字机推进算作阅读，计入「阅读记录」。

### 5.3 歌词

像看歌词一样读书：**当前行固定在视线高度**，其余行淡下去但始终看得到，读完一行自动往上走一行。它帮你**不跳行、不走神**，不承诺让你读得更快。

#### 5.3.1 开始与退出

1. 在「带读」里选「歌词」，按需调整选项。
2. 点「**从本页开始**」，或直接按 **Shift+L**。
3. 退出：面板里点「**退出歌词**」，或按 **Shift+L** / **Esc**，或点迷你控制条上的退出按钮。

歌词运行时，轻阅会临时把排版切成**滚动**、**单栏**，并按「字号」选项放大文字、把行距至少调到 2.0。**退出后恢复原来的排版**，并停在你刚读到的那一行所在的页。读完一章会自动接着下一章，读到全书最后会提示「全书完」。

#### 5.3.2 选项说明

| 选项 | 可选值 | 说明 |
|---|---|---|
| **推进** | 自动 / 跟听书 / 手动 | 默认「自动」，见下表 |
| **聚焦** | 1 行 / 3 行 | 一次突出几行，默认 1 行。3 行时左侧有一条强调色竖线标出聚焦区 |
| **其余行** | 淡显 / 隐藏 | 聚焦行以外的文字是变淡（默认）还是隐去 |
| **位置** | 偏上 / 居中 | 当前行停在屏幕高度约 40% 处（默认）或正中 |
| **字号** | 原大 / ×1.2 / ×1.4 | 在你现有字号上放大，默认 ×1.2 |
| **速度** | 同打字机 | 只在「自动」推进时出现，和打字机共用速度和快捷档；旁边会显示大约「≈ N 秒/行」 |
| **标点停顿** | 开 / 关 | 同打字机，「自动」推进时有效 |

| 推进方式 | 怎么走 |
|---|---|
| **自动** | 按设定的字/分速度一行一行往前走，遇到长行、标点会多停一会儿 |
| **跟听书** | 听书读到哪一句，歌词就走到哪一行。还没开始听书时会提示「开始听书后，歌词会跟着朗读走」 |
| **手动** | 不自动走，轻点屏幕**下半部分**前进一行、**上半部分**后退一行；也可以用键盘 ↓ / ↑ |

#### 5.3.3 运行中的操作

| 想做什么 | 怎么做 |
|---|---|
| 暂停 / 继续（自动推进时） | 轻点正文、按 **空格**，或点迷你控制条的按钮 |
| 下一行 / 上一行 | **↓** 或 **J** / **↑** 或 **K**（→ / ← / PageDown / PageUp 也可以）；手动推进时还可以轻点下半屏 / 上半屏，或迷你控制条上的「上一行」「下一行」 |
| 跳到某一行 | 直接点那一行（聚焦区以外淡显的行）。跟听书时，听书也会从那一句开始读 |
| 加速 / 减速（自动推进时） | **Shift+↑** / **Shift+↓**，或迷你控制条上的 − / + |
| 想往回翻看 | 直接滚动页面。歌词会停止跟随，并在当前行所在那一侧的屏幕边缘显示「**回到当前行**」，点它（或轻点正文）就回去 |
| 退出 | **Esc**、**Shift+L**，或迷你控制条上的退出按钮 |

跟听书时轻点正文是呼出 / 收起工具栏。长按选中文字时，自动推进会暂停。

**迷你控制条**：自动推进时和打字机一样（暂停、速度、本章剩余、− / +、退出）；手动推进时是「上一行 · 手动 · 下一行 · 退出」；跟听书时显示「跟听书」和退出按钮。

#### 5.3.4 和听书一起用

- 听书正在播放时开始歌词，歌词会**自动跟听书**。
- 歌词（自动或手动）运行时开始听书，歌词会改为跟听书，并提示「歌词改为跟随听书」，不会被停掉。
- 也可以在「带读 → 听书」里，听书播放时点「**显示歌词视图**」。
- 在歌词里把推进改回「自动」或「手动」，会暂停听书。

#### 5.3.5 其他说明

- 固定版式的书不支持歌词，会提示「固定版式的书暂不支持歌词模式」。
- 墨水屏模式下歌词是整屏跳；系统开启「减少动态效果」时不做平滑滚动，直接跳到下一行。
- 打开任何面板、弹出提示或切到后台时，自动推进会暂停。

### 5.4 听书

「带读」里的「听书」分段只放一个入口：点「**打开听书**」进入听书面板，所有听书设置都在那里，见 [03-声音](03-声音.md)。

### 5.5 带读之间的关系

| 你开始了… | 正在运行的会怎样 |
|---|---|
| 自动翻页 | 打字机、歌词退出 |
| 打字机 | 自动翻页停止（提示「已停止自动翻页」），听书暂停（提示「已暂停听书」），歌词退出 |
| 歌词 | 打字机退出、自动翻页停止；听书在播放时歌词改为跟听书，否则不影响 |
| 听书 | 打字机退出（提示「已退出打字机模式」）；歌词改为跟听书 |

带读推进的时间都计入「阅读记录」。

## 8. 把书摆得舒服：阅读界面设置

### 8.1 排版面板

打开方式：电脑点顶栏「排版设置」图标；手机点底栏「排版」。面板分三组，不常用的收在每组的「**更多**」里（展开状态会记住）：

| 分组 | 设置 | 范围 / 选项 | 说明 |
|---|---|---|---|
| 文字 | **字号** | 滑块 8–64，数字框可输入 | 也可点「A−」「A+」逐级调整 |
| | **行距** | 1.2–2.6 | 默认 1.8 |
| | **边距** | 2%–16% | 页面左右留白，默认 6% |
| | **字体** | 默认 / 宋体 / 黑体 / 楷体，以及系统字体、自定义字体 | |
| | 更多 › **字距** | 0–0.20em | 字与字之间的距离 |
| | 更多 › **对齐** | 两端对齐 / 左对齐 | |
| | 更多 › 导入字体 | ttf / otf / woff2 | 仅桌面版 |
| 配色 | **主题** | 五个色块 | 见下表 |
| | **调暗** | 0–60% | 在正文上叠一层半透明暗色，**不改变系统亮度**，对所有主题生效 |
| 版式 | **方式** | 翻页 / 滚动 | 翻页像纸书一页一页；滚动是上下连续滑动 |
| | **跨章** | 连续滚动 / 逐章 | 滚动时才出现；连续滚动让章与章首尾相接 |
| | **分栏** | 单栏 / 自动双栏 | 翻页时才出现；自动双栏在宽屏时显示两栏，窄屏仍为一栏 |
| | 更多 › **竖屏** | 单栏连续 / 同横屏 | 竖着拿设备时是否临时改为单栏连续滚动 |
| | 更多 › **进度** | 页码+百分比 / 页码 / 百分比 | 控制页脚和底栏显示哪种进度 |

这些设置**对所有书籍生效**。想一键还原，到「设置 → 阅读偏好 → 恢复默认排版」。

### 8.2 正文主题

排版面板里的「主题」是五个色块，每个色块上写着一个「文」字，直接预览底色和文字颜色。鼠标悬停时会显示主题名，读屏软件也会读出名字：

| 色块 | 名字 | 效果 |
|---|---|---|
| 白底黑字 | **白色** | 浅色 |
| 米黄底 | **米黄** | 类似旧纸张，暖色调（护眼模式的默认底色） |
| 浅绿底 | **护眼绿** | 偏绿的柔和底色 |
| 深灰底浅色字 | **夜间** | 深色 |
| 斜切的半白半黑色块 | **跟随外观** | **默认**。浅色外观时用白色，深色外观时用夜间 |

> 正文主题和应用外观是两个独立的设置。应用外观在「设置 → 通用 → 外观」（跟随系统 / 浅色 / 深色）里改，它决定书架、设置等界面的配色。如果你在阅读页明确选了某个主题（比如米黄），它就不会再跟着外观变化；只有「跟随外观」会自动切换。「阅读模式」里的夜读、护眼场景改的也是这个正文主题。

### 8.3 翻页的方法

- **点屏幕**：点左侧三分之一翻到上一页，右侧三分之一翻到下一页，**中间三分之一**呼出或隐藏工具栏。点到页面最上沿、最下沿（章名、页码那条带）也按同样的左 / 中 / 右分区处理。
- **滑动**：触屏左右滑动翻页；翻页模式下上下滑动也能翻页。滚动模式下滑到本章末尾后继续上滑，就进入下一章。
- **键盘**：**←** / **PageUp** 上一页；**→** / **PageDown** / **空格** 下一页。
- **按钮**：鼠标移到阅读区时，左右两侧会出现上一页 / 下一页按钮。
- **章节**：底栏进度条两端的按钮是「上一章」「下一章」。

> 打字机运行时轻点正文是暂停 / 继续；歌词运行时轻点的效果见 [5.3.3](#533-运行中的操作)；点睛阅读开启时，点到概念或注会弹出解释卡片而不是翻页。

### 8.4 浮动工具栏

阅读页的顶栏和底栏是浮在正文上的，正文始终占满整个窗口：

- 翻页时工具栏自动隐藏，只剩正文。
- 点屏幕中间，或把鼠标移到窗口最上 / 最下边缘，工具栏重新出现（开着「沉浸」时只有轻点才会出现）。
- 打开任何面板时工具栏不会自动收起。

**顶栏**（电脑）从左到右：返回藏书、书名与当前章、目录、笔记、书签、听书、AI 助手、背景音、书内搜索、阅读模式、排版设置、全屏阅读。手机上顶栏只保留返回、书签、AI 助手、背景音和书内搜索，其余放到底栏：**目录 / 笔记 / 听书 / 模式 / 排版**。

### 8.5 全屏

- 电脑点顶栏最右的「全屏阅读」。进入全屏后工具栏会自动隐去，直接进入纯文字状态。
- 全屏且工具栏隐藏时，右上角有一个悬浮的「退出全屏」按钮；也可以按 **Esc** 退出。
- 手机上没有全屏按钮，隐藏工具栏后就是满屏阅读；想连系统状态栏也隐藏，打开「沉浸」（见 [3.5](#35-沉浸)）。

### 8.6 进度显示与跳页

- **页脚**：页面上方显示章名，下方显示进度（按排版面板「进度」的选择显示页码、百分比或两者），并提示「本章剩 N 页」或「本章最后一页」。开着「沉浸」时章名和本章剩余不显示。
- **进度条**：拖动底栏进度条时，会在气泡里预览将要到达的章节和位置，松手才跳转。
- **跳到指定位置**：点底栏右侧的页码 / 百分比，弹出跳转框，输入**页码**（如 `120`）或**百分比**（如 `35%`），点「跳转」。如果这本书带有纸书页码，跳转框里还会显示「纸书第 N 页」。
- **跳回原处**：通过进度条、跳转框、目录等跳走后，底部会出现「回到第 N 页」按钮（约 12 秒内有效），点一下回到跳转前的位置。

> 页码是按当前字号、行距和屏幕大小实时计算的，改了排版或换了设备，页数会随之变化——跳转框里也有这条提示。百分比则始终不变。
