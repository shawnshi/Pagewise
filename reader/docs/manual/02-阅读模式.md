# 二、阅读模式与阅读界面

这一篇讲两件事：

1. **阅读模式**：书页怎么动、怎么带你读。顶部是**伴读**（基础版 / 智能版），下面分两组：
   - **场景**：夜读、护眼、墨水屏、大字、沉浸——一键套用一组设置，再点一次恢复原样；
   - **带读**：自动翻页（滚动方式下叫自动滚动）、打字机、歌词、朗读（同一时间只运行一个）。
2. **排版与交互**：书页的字号、字体、主题、物理显示校准、翻页 / 滚动、单手/三区触控与硬件波形控制（见第 8 节）。

> 本篇主要面向 EPUB、MOBI、AZW3、FB2、TXT、HTML、Markdown 等**流式电子书**；PDF 阅读器控制见 [04-使用说明](04-使用说明.md#6-pdf-阅读)。伴读单独成篇，见 [05-伴读](05-伴读.md)；朗读见 [03-声音](03-声音.md)。

---

## 1. 打开「阅读模式」面板

| 设备 / 情境 | 入口 |
|---|---|
| 大屏平板 / 横屏 | 阅读页顶栏「**阅读模式**」图标按钮 |
| 窄屏 / 竖屏 | 点屏幕中间呼出工具栏，底栏点击「**模式**」 |
| 键盘快捷键 | 按 **M** |

同一时间仅展开一个侧边/底部面板；打开「阅读模式」会自动收起目录、排版等面板。

---

## 2. 场景与状态恢复

夜读、护眼、墨水屏、大字与歌词均会在现有排版之上**记录旧值、临时覆写、关闭时精确还原**：

- 开启场景后在排版里调过的字号等数值会被记住，下次开启同场景时沿用；
- 在场景开启中手动切到别的阅读主题（例如夜间或米黄），关闭场景时尊重你的显式选择；
- 大字、墨水屏或沉浸开启期间，排版面板顶部会给出「场景开启中」提示，可直接跳转管理。

---

## 3. 五种预设场景

### 3.1 夜读

切换为深色纸墨主题；支持在 ⓘ 中设置「定时开启」（默认 `22:00` 到 `07:00`），仅当定时调度打开时才在窗口结束后自动恢复。当墨水屏模式启用时，人工手动开关不会被定时规则强行覆盖。

### 3.2 护眼

切换至暖色主题（米黄或护眼绿），并在连续活跃阅读达到设定间隔（20 / 30 / 45 分钟）时弹出轻提示。墨水屏模式下为避免残影与无效耗电，休息提示不启用每秒高频倒计时动画，提供静态「休息好了」「跳过」「稍后提醒」操作。

### 3.3 墨水屏（E-Ink）

首次在 Android / BOOX 墨水屏设备运行时默认针对 E-Ink 屏幕适配，也可在「**设置 → 墨水屏与硬件**」或阅读模式面板随时切换：

| 优化项 | 行为说明 |
|---|---|
| **高对比黑白灰阶** | 严格映射到纯黑白纸墨与 Y14/Y11/Y7 灰阶，取消阴影、毛玻璃、过渡动效与翻页动画；支持墨水屏深色反显并自动收紧全屏刷新间隔（≤8 页） |
| **硬件 EPD 波形** | 日常翻页采用 Regal / 普通高清晰刷新，按「全屏清残影间隔（0–50 页）」周期性触发 GC16；滚动与 AI 流式输出期间进入 A2 / DU 快速波形，结束后自动补一次 Regal 精刷 |
| **打字机与歌词** | 打字机最少按句显示（避免逐字全屏闪烁）；歌词模式按整屏跳转，禁止平滑滚动 |
| **伴读与划线** | 伴读改用黑/白线型（实线、点线、空心圆点）区分；用户自建高亮叠加可辨识底纹与下划线 |

### 3.4 大字

| 档位 | 正文字号 | 联动排版 |
|---|---|---|
| **大**（默认） | 24px | 行距 2.0、字距 0.05em、黑体、左对齐、单栏并放大工具栏触控热区 |
| **特大** | 30px | 同上，段落间距增大 |

### 3.5 沉浸

隐藏页眉章名与工具栏，仅留正文；支持开启「隐藏页码」。在 Android 上联动隐藏系统状态栏与导航栏并保持屏幕常亮。

---

## 4. 带读：自动翻页、打字机、歌词、朗读

| 带读模式 | 作用 | 与其他模式关系 |
|---|---|---|
| **自动翻页** | 按 `3–300` 秒/页定时翻页，支持设置与底部迷你条调速 | 与打字机、歌词互斥 |
| **打字机** | 按设定速度逐字（非墨水屏）或逐句显现正文，支持标点停顿 | 与自动翻页、歌词互斥，触发会暂停朗读 |
| **歌词** | 突出当前 1 行 / 3 行，支持自动推进、手动点按或**跟随朗读** | 墨水屏下自动切为整屏翻跳 |
| **朗读** | 见 [03-声音](03-声音.md) | 独立面板与迷你胶囊控制 |

> **零轮询省电机制**：连续阅读计时器会在读者超过闲置阈值（默认 5 分钟未翻页/交互）后自动挂起定时器，切回前台或再次交互时无感恢复；自动夜读定时仅在开启计划时按需运行。

---

## 5. 排版面板与物理校准

在阅读页点「**排版**」调整字号（8–64）、行高（1.0–3.0）、页边距（2%–20%）、字距、两端对齐、字体族、进度显示（页码+百分比 / 页码 / 百分比）与单双栏。在「**设置 → 阅读与声音 → 物理显示校准**」中可用实体直尺校准物理毫米与 CSS 像素映射（未手动校准时优先读取设备上报 `densityDpi`）。

---

## 6. 点按分区、手写与硬件按键

| 操作方式 | 行为 |
|---|---|
| **标准三区点按** | 左 30% 上一页、中 40% 呼出/隐藏工具栏、右 30% 下一页 |
| **单手模式** | 可选开启单手区：上三分之一上一页、下三分之二下一页 |
| **硬件物理键** | BOOX 音量键（±，非 TTS 朗读中）、方向键（DPAD 上/下/左/右）、PageUp/PageDown、蓝牙翻页环（媒体上一首/下一首，非 TTS 朗读中）均可翻页 |
| **原生手写叠加（BOOX）** | Wacom 电磁笔可在阅读区直接落笔，自动屏蔽手掌误触；按住笔杆侧键擦除，停笔后触发 Regal 清刷 |
| **图表灯箱与脚注** | 点击 EPUB 正文插图或表格可放大查看与缩放；点击脚注上标或内联引用弹出浮层预览与跳转 |

---

## 7. 进度条、跳回原处与快捷键

- 拖动底栏进度条时启用极速预览（松手后再 Regal 精刷并落盘）；
- 通过目录、书内搜索、章节按钮或笔记深链跳走后，底部固定保留 **「回到刚才位置」** 胶囊按钮（即使工具栏收起亦常驻点击，无 3 秒自动消失闪烁）；
- 常用键盘快捷键：`M`（阅读模式）、`Shift+T`（打字机）、`Shift+L`（歌词）、`D`（伴读）、`[` / `]`（上/下一个要句）、`←` / `→` / `PageUp` / `PageDown`（翻页）、`Esc`（退出模式/关闭弹窗）。
