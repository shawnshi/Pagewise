# 五、伴读

**伴读（Companion）** 在阅读时辅助定位重点、解释关键概念：**让重点自己浮出来**。同一开关下提供两个可随时切换的版本：

| 版本 | 核心能力 | 是否联网 |
|---|---|---|
| **基础版** | 离线分词着墨与视觉引导，帮助长句一目了然 | 纯本机离线，打开即用 |
| **智能版** | 调用你自有配置的 AI 服务，标出**要句**、**概念**与**注释**，并提供**章首要义**、**全书脉络**与**速读视图** | 需要网络并消耗自有 API Key 额度 |

两个版本均**不改写、不隐藏、不删减原文**。固定版式图书（如纯图漫与版式 PDF 的常规页）请使用阅读助手功能。

---

## 1. 开启与切换版本

1. 在流式电子书阅读页打开「**阅读模式**」面板（顶栏图标、底栏「模式」或按 **M**）。
2. 打开顶部的「**伴读**」总开关，选择「**基础**」或「**智能**」。
3. 系统记住你的上次选择，之后按快捷键 **D** 可直接开/关伴读。

---

## 2. 基础版：离线分词引导

- **工作原理**：完全在本地完成中文分词与常用词合并，只调节色彩/墨水屏强调强度，不触发排版重排。
- **墨水屏适配**：当开启墨水屏场景时，自动切换为高对比黑白文字加粗与细线引导，不再叠加粉红/青绿等彩底或半透明彩色 `rgba`。

---

## 3. 智能版：隐私边界与自有服务授权

智能版严格遵循 **BYOK（自带密钥）原则**，知页不内置免费代理，也不会自动转发至其他第三方中转站：

- 首次点击「**智能**」且已配置「**设置 → AI 服务**」中的 DeepSeek / OpenAI / Google Gemini / OpenRouter 密钥时，会明确展示当前将请求的服务商名称，可选择「**仅本书开启**」「**所有书开启**」或「**暂不开启**」；
- 未配置 AI Key 时无法激活联网智能版，请先配置或直接使用离线**基础版**；
- 已经完成分析并缓存在本地数据库的章节结果可**完全离线复用**。

---

## 4. 原文里的三种标记

| 标记类型 | 常规主题样式 | BOOX 墨水屏高对比样式 | 含义 |
|---|---|---|---|
| **要句** | 句下朱红实线 | 黑色 **2px 实线**下划线 | 论点、定义、结论或关键转折句 |
| **概念** | 青色 + 点状下划线 | 文字加深 + **点状**下划线 | 专有术语、重要人物与关键概念 |
| **注** | 词尾赭色圆点 | 词尾**空心高对比圆点** | 典故、文化背景或书外补充注释 |

---

## 5. 交互卡片与笔记收归

- **轻点「概念」或「注」**：弹出解释卡片（可「展开」交由 AI 阅读助手延展讨论，或选「不用标这个」永久隐藏该条）。
- **选中「要句」文字**：弹出选区浮条点击「**为什么标**」查看依据；点击「**我也觉得**」或「**写想法**」即可直接转为个人永久高亮与笔记（遵循先确认编辑、后写入原则）。

---

## 6. 脉络分屏、速读与防剧透

| 视图 / 机制 | 说明 |
|---|---|
| **章首要义** | 读完/预处理完成一章后在章首给出核心梗概与最多 3 个要点跳转，可随时收起 |
| **脉络（分屏/抽屉）** | 在大于 `820dp` 的墨水屏平板上自动以右侧非遮挡分屏并列展开「大纲」与「本书词表」，点击任意条款即刻跳回原文 |
| **速读视图** | 按章集中列出要义与要句用于总览和复盘，不代替正文细读 |
| **小说防剧透** | 识别或手动指定为小说时，释义、脉络与上一章回顾仅基于**已读进度**之前的内容，禁止提示或剧透后续情节 |
| **纠偏与重来** | 支持调整标注密度（少 / 标准 / 多）、开关单类标记、重新分析当前章或清除本书本地缓存 |

---

## 7. 快捷键

| 按键 | 作用 |
|---|---|
| **D** | 开 / 关伴读（沿用上次选定版本） |
| **[** / **]** | 跳至当前章的上一个 / 下一个要句 |
| **M** | 打开 / 关闭阅读模式面板 |
| **Esc** | 关闭当前伴读卡片、脉络或速读视图 |
