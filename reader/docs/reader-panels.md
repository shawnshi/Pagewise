# 阅读器面板：「排版」与「模式」的分工

> 2026-10-07 · 状态：已实现 · 范围：可重排书籍阅读器（`ReaderView`）
> 相关：`docs/reading-modes.md`（各模式细节）、`docs/continuous-scroll.md`（跨章连续滚动）、`src/services/readingModes/presets.ts`（快照引擎）

## 1. 问题

改版前两个面板各管一部分，又互相重叠：

| 重叠 | 「排版」里 | 「模式」里 |
|---|---|---|
| 正文主题 | 主题圆点（含米黄、护眼绿、夜间） | 夜间卡片、护眼卡片（含「底色」米黄 / 护眼绿） |
| 分栏 | 分栏：单栏 / 自动双栏 | 双栏卡片（同一个设置） |
| 字号等 | 字号、行距、边距、字体 | 大字卡片（大 / 特大） |
| 页眉页脚 | 进度显示 | 沉浸 · 隐藏页码 |
| 调暗 | — | 护眼里的「调暗」（只在暖色主题下生效） |

同一个值有两个入口，读者不知道该去哪改，也不知道两边谁说了算。字距、两端对齐会被「大字」改掉，却没有任何地方能手动调。

## 2. 原则

1. **排版 = 书页长什么样。** 所有静态的外观与版式「值」只在这里调，每个值只有这一个家。
2. **模式 = 书页怎么动、怎么带你读。** 只放随时间运行的体验（自动翻页 / 自动滚动、打字机、歌词、听书联动）和阅读辅助（点睛阅读：基础版 / 智能版），以及它们自己的参数。
3. **场景是快捷方式，不是第二份设置。** 「模式」顶部的场景卡片一键套用一组排版值（走现有的快照引擎：开启记下原值，关闭写回），自己不保存任何排版值的副本，也不在详情里放排版控件，只列出「会调整什么」并提供「在排版里微调」的跳转。
4. **场景详情里只放场景自己的行为**：什么时候自动开启（夜读定时）、开着时做什么（护眼的休息提醒）、选哪一套（大字的大 / 特大）。
5. **互相跳转代替重复**：模式 → 排版（「在排版里微调」，定位到对应分区）；排版 → 模式（场景提示条的「管理」）。

## 3. 信息架构

### 3.1 「排版」面板（工具栏「A」，按钮 title 仍是「排版设置」）

| 分区 | 设置 | 存储键 | 备注 |
|---|---|---|---|
| （顶部提示） | 已开场景提示 + 管理 | — | 大字 / 墨水屏 / 沉浸开着时显示，点「管理」打开模式面板 |
| 文字 | 字号 | `reader.fontSize` | A− / 滑条 / A+ / 数字框 |
| | 行距 | `reader.lineHeight` | |
| | 边距 | `reader.gap` | |
| | 字体 | `reader.fontFamily` | |
| | 更多 › 字距 | `reader.letterSpacing` | **新露出**（原先只有大字会改它） |
| | 更多 › 对齐 | `reader.justify` | **新露出**：两端对齐 / 左对齐 |
| | 更多 › 导入字体 | — | 仅桌面版 |
| 配色 | 主题 | `reader.theme` | 白 / 米黄 / 护眼绿 / 夜间 / 跟随外观（5 个圆点，顺序不变） |
| | 调暗 | `readingMode.eyeCare.dim` | **从护眼移来**，改为对所有主题生效 |
| | （墨水屏提示） | — | 墨水屏开着时说明配色按黑白显示 |
| 版式 | 方式：翻页 / 滚动 | `reader.flow` | 竖屏锁定时下方提示「横屏后恢复」 |
| | 跨章：连续滚动 / 逐章 | `reader.continuousScroll` | 仅生效方式为滚动、非固定版式时显示 |
| | 分栏：单栏 / 自动双栏 | `reader.maxColumnCount` | 仅保存的方式为翻页时显示；大字 / 歌词强制单栏时提示 |
| | 更多 › 竖屏 | `reader.portraitScroll` | 单栏连续 / 同横屏 |
| | 更多 › 进度 | `reader.progressDisplay` | 页码+百分比 / 页码 / 百分比 |

「更多」用原生 `<details>` 折叠，展开状态按设备记在 `localStorage`（读不到就默认收起）。手机底部抽屉因此保持在一屏多一点。

### 3.2 「模式」面板（工具栏「阅读模式」，底栏「模式」）

| 分组 | 内容 |
|---|---|
| 顶部 | 点睛阅读（插槽 `DianjingToggle`）：标题「点睛阅读」+ 副标题「让重点自己浮出来」+ 总开关；开着时「基础 / 智能」分段，下面只显示所选版本的选项——基础：明显程度、颜色（`readingMode.wordGuide.*`）；智能：密度、标记、体裁、速读 / 脉络、状态（`dianjing.*`）。所选版本存 `dianjing.level`（随同步）。打字机 / 歌词运行时的进度与剩余时间 |
| 场景 | 夜读 · 护眼 · 墨水屏 · 大字 · 沉浸（开关卡片，ⓘ 展开详情） |
| 带读 | 自动翻页（滚动方式下叫「自动滚动」）· 打字机 · 歌词 · 听书；各自的速度、粒度、声音、推进方式等参数，同一时间只运行一个 |

原先底部的「实验」组（单独的按词着色开关）已并入点睛阅读，成为基础版；两个版本同一时间只生效一个，不再需要「互斥」提示。

### 3.3 场景卡片

| 场景 | 会调整（排版里的值或渲染方式） | 场景自己的选项 | 关闭时 |
|---|---|---|---|
| 夜读 | 主题 → 夜间 | 定时开启（从 / 到） | 主题写回开启前的值 |
| 护眼 | 主题 → 米黄或护眼绿（记住你最后在排版里选的暖色） | 休息提醒（20 / 30 / 45 分钟） | 主题写回 |
| 墨水屏 | 黑白高对比、文字加粗、无翻页动画；打字机最少逐句 | — | 打字机粒度写回 |
| 大字 | 字号 24 / 30、行距 2.0、字距、边距、黑体、不两端对齐；强制单栏；工具栏按钮放大 | 大 / 特大 | 排版值写回；在排版里调过的字号等记为大字自己的值，下次沿用 |
| 沉浸 | 隐藏页眉章名与本章剩余；工具栏轻点才出现；手机隐藏状态栏并常亮 | 连页码也隐藏 | 恢复 |

夜读、护眼、大字的详情里有「在排版里微调」，打开排版面板并滚到对应分区（配色 / 文字）。

不做「专注滚动」场景：它等于「版式 › 滚动 + 跨章连续」，两步即可，包成场景只会多一个入口。

## 4. 迁移与兼容

- **数据模型不变**，不递增 `SETTINGS_VERSION`。预设快照（`readingMode.presets`）的格式、键名、叠加规则不变，已有记录照常恢复（`test:sync-settings` 覆盖）。
- **双栏卡片删除**：值一直是 `reader.maxColumnCount`，只在排版里调。
- **护眼「底色」选择删除**：在排版里点米黄 / 护眼绿即记为 `readingMode.eyeCare.theme`，下次开护眼用它。
- **调暗改为通用**：`readingMode.eyeCare.dim` 不再只在暖色主题下生效。为了不让老用户突然变暗，首次加载时若当前不是暖色主题而 `dim > 0`（此前看不到效果），把它清零（`localStorage` 标记 `lightread-dim-general`，只做一次）。
- **新露出字距、对齐**：键早已存在并参与同步，只是补上控件。
- 定时夜读、休息提醒、沉浸·隐藏页码仍在模式的场景详情里，键不变。

## 5. 理由

- 读者找设置时按「我想让字/颜色/版面变成什么样」去排版，按「我想被带着读」去模式；两个心智模型不交叉。
- 场景卡片保留「一键 + 可撤销」的价值（关闭即恢复原样，叠开也能正确回退），但不再和排版争夺同一个值的所有权。
- 调暗是夜里最常用的控件，不该只在护眼下可用。
- e2e 依赖的选择器保持语义：`button[title="排版设置"]`、`.theme-btn`（5 个，第 3 个护眼绿）、排版里的 `.seg` 按钮文案「翻页」「滚动」、`[title="阅读模式"]`、`.rm-panel` 的「自动翻页」页签、`.auto-panel`、`.rm-close`。
