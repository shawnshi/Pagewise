## 3. 调研结论（摘要）

详见各文档；这里只列影响决策的结论。

- **阅读模式**（docs/research/reading-modes-landscape.md）：主流中文阅读 App 都没有「单行 / 三行自动滚动」的歌词式模式，是可以占住的空白；只显示 1–3 行阅读稍慢（约 9%）但理解不降，**不能回看会损害理解** → 歌词模式保留上下文（淡显）而不是只露一行。大字依据工信部适老化规范（正文 ≥18dp、触控 ≥60dp）。护眼：「防蓝光」「绿色护眼」缺乏证据，20-20-20 休息提醒有小幅 RCT 支持 → 文案不承诺「保护视力」。沉浸：Android 隐藏系统栏、常亮可做；勿扰需用户授权，放后期。
- **仿生阅读**（docs/reading-modes.md）：4 项研究均无提速 / 提升理解；名字是注册商标的中译，英文界面避开 Bionic → 只做实验性排版偏好。
- **背景音**（docs/research/reading-ambient-audio.md）：主流阅读 App 都没有内置环境音，可占空白；有歌词音乐、听得懂的人声伤害阅读最大；噪声对 ADHD 小幅有益、对普通人小幅有害 → 默认关、低音量、不承诺提升专注。只用 CC0 / 公有领域 / CC BY；不用 Pixabay（禁止原文件再分发）、BBC 音效（非商用）。噪声实时合成与录音几乎无差别且永不重复。
- **点睛阅读**（docs/dianjing-reading.md）：错误或过多的预标注会**降低**理解，少而准的标注有益，对新手效果最明显；Scim（论文速读）把找信息时间从 118 秒降到 94 秒但不提升准确率 → 质量门槛「明显错标 ≤5%」，默认只标约 8% 的文字，绝不隐藏或改写原文。由应用给句子编号、模型只回编号，杜绝编造引文。DeepSeek-V4-Flash 关思考首字 1.3 秒，一本 20 万字的书成本约 ¥1（价格未核实）。
- **读书方法**（docs/manual/01-读书方法.md）：古今中外 28 种方法、8 个有出处的故事、「选书 → 略读 → 精读 → 思考与输出 → 复习」流程。北大图书馆的故事**出处无法核实**，手册如实说明，并列出可证实的史实（1918–1919 年在北大图书馆任职、「先博而后约」、「不动笔墨不读书」）。
- **使用手册审查**（docs/manual/）：按真实代码写成，顺带发现 13 处体验不一致（见阶段 0）。

## 4. 产品计划

原则：每个阶段可单独发版；先打磨已有体验，再加新能力；新能力上线时同步更新使用手册。

### 阶段 0 · 打磨与收尾（v1.6.1，约 1 天）
- 提交已完成未提交的四项：默认台湾腔女声（含旧默认迁移）、离线模型算力提示与卡顿改用在线、打字机速度直接输入、打字机进度与剩余时间。
- 修使用手册审查发现的问题：Android 隐藏「本地模型」；AI 首次使用推荐「内置试用通道」；「笔记」面板统一一个名字；主题按钮加名字；PDF「自动阅读」改为「自动翻页」；表情符号图标换成 SVG；「语速与音色对下一段生效」改为「下一句」；字号滑条与输入范围一致；推荐 / 默认标签统一。
- 提交使用手册 docs/manual/ 与调研文档。
- **验收**：单测、冒烟全过；手册与界面文案一致。

### 阶段 1 · 阅读模式与背景音（v1.7）
- 「阅读模式」面板改为三组：**显示**（夜间、护眼、墨水屏、大字）、**版面**（沉浸、双栏）、**带读**（自动翻页、打字机、歌词、听书，同时只开一个）。
- **歌词**：1 行 / 3 行，当前行固定在屏幕 40% 处，其余行淡显；自动（字/分）/ 跟听书 / 手动；轻点暂停，手动滑动时暂停跟随并给「回到当前行」。
- **大字**：一键预设（字号 24/30、行距 2.0、字距 0.05em、单栏、大按钮），关闭时恢复原设置。
- **沉浸**：Android 隐藏系统栏、屏幕常亮。
- **背景音（合成版）**：场景卡片（雨夜书房、林间风声、专注噪音、夜曲铺底）+ 音量 + 定时；听书时自动压低；跟随睡眠定时淡出。
- **验收**：歌词模式在 K70 / K30 Pro 连续 30 分钟不跳行不错位；背景音手机上连续播放 1 小时无断续、耗电可接受；手册更新。

### 阶段 2 · 点睛阅读 MVP（v1.8）
- 中转新增点睛接口（DeepSeek-V4-Flash，关思考，额度按 Q5）；首次开启征得同意。
- 原文内三种标记：**要句**（朱红实线下划线）、**概念**（青墨色 + 点状下划线，点一下按上下文解释）、**注**（句末小圆点）；密度三档；章首「要义」卡片。
- 长按要句：为什么标、翻译、收为我的划线、不对就删。
- 按书 + 段落缓存，读过的部分离线可看；只同步用户收下的标记。
- 论文阅读器「AI 辅读」改名「论文 Agent」。
- **验收**：打开新章节 3 秒内出现第一批标记（p95）；36 段评测集上明显错标 ≤5%；不改动 DOM，划线、听书、搜索、进度均不受影响。

### 阶段 3 · 点睛阅读完整版与体验深化（v1.9）
- 点睛：「脉络」大纲面板、「速读」视图（只看要句 + 要义，可跳回原文）、中英对照与文化注释、小说防剧透。
- 组合：打字机遇要句放慢、速读时跳过非要句；听书在要句前稍作停顿、章首先读要义；歌词跟听书。
- 墨水屏（黑白、无动画、加粗）；护眼（暖色、应用内调暗、20 分钟休息提醒）；夜间定时。
- 背景音录音包（R2 按需下载，CC0 素材 + 来源与许可页）。
- 应用内「使用手册」页面。

### 阶段 4 · 探索项
- 仿生阅读（实验，默认关）；沉浸模式的勿扰；增强音色包（视 Q1）；Android 离线听书（sherpa-onnx 已支持，先在真机测速）。

## 5. 「做到极致」的检验标准

- **快**：开书 1 秒内可读；翻页无卡顿；听书起播 2 秒内、播放中零断续；点睛首批标记 3 秒内。
- **准**：页码、剩余时间与实际偏差小；点睛错标 ≤5%；不编造引文。
- **不打扰**：任何模式都不遮挡正文、不隐藏原文、可一键退出；默认关闭会改变阅读习惯的功能（背景音、点睛、仿生）。
- **诚实**：不宣传没有证据的效果（提速、防蓝光、提升专注）；出处不明的说法如实标注。
- **一致**：一个功能一个名字，界面、手册、代码一致；深色 / 护眼 / 墨水屏主题下都好看。
