## 授权与目标

用户已确认：藏书、正在阅读列表、书籍详情、全部笔记、阅读统计、设置、使用手册改为 Android 原生实现，并将原有设置与阅读统计迁至原生存储。EPUB/PDF 正文阅读器不在本轮替换范围。

- 使用 Kotlin 与现有 Android 原生控件，不新增第二个 WebView 或第二套书库。
- 书籍、批注、手动标签/分类、书单与阅读位置保留现有 SQLite 表及标识。
- 设置与统计增加原生表，共享现有库文件；不改写或清空原 localStorage/IndexedDB 迁移源。
- 既有阅读器通过受保护的 Tauri IPC 读写同一原生状态。JavaScript 内存快照不是第二个持久化主存储。
- 继续复用现有原生导入任务、TTS/MediaSession、窗口与 EPD 所有者。

## 迁移合同

1. 新版启动先查询原生完成回执；已完成则不再读取或覆盖来自旧 WebView 的快照。
2. 读取并严格校验设置、`lightread-stats` 记录，以及 `lightread-sync` 中的 deviceId/hash 映射；不读取旧同步账户、基线或密钥之外的无关字段。
3. 分批暂存并核对页序号、摘要、唯一键和总数；断点重试不能加总两次。
4. 在同一 SQLite 事务内提交设置、原设备标识、hash 映射、统计行和完成回执。只有同一不可变行 key 的合并取较大计数；不同 id:/h: 行仍按原业务加总，h 行代表已落地差额。不凭标题或现有书目重算。
5. 失败停在迁移/恢复状态；不能降级为空设置、空统计或悄悄建立替代书库。
6. 完成后只写原生存储。旧副本只代表迁移前状态；迁移后新增数据须由原生备份恢复，不承诺降级旧 APK 自动携带新增记录。
7. 设置更改采用字段前值校验与修订号；统计增量采用带过期拒绝规则的幂等请求，未知提交须查回执，不能盲目重放。
8. 自定义库位置必须明确解析并验证；不可读或不支持的位置报错，不能静默改用默认目录。

- 原生页面：统一原生导航、列表/详情/笔记/统计/设置/离线手册，按当前 Android 功能逐项对齐。
- 整体验收：启动迁移、取消/重启/重复提交、现有阅读器共享状态、返回导航、数据不丢失及各页原生交互；独立复核。

## 原生页面与业务边界

- 藏书：原生搜索、排序、分页、分类/主题/特征/未分类与高级条件筛选、多选及批量状态/置顶/移除/标签操作。全局查询复用现有 `libraryQuery/librarySession`，不在 Kotlin 复制另一套查询规则。
- 正在阅读：保留在读、最近、想读、暂缓、已读、弃读六组及既有状态推断/排序；恢复阅读前的结果顺序、页码与书籍位置。
- 详情：封面、书目编辑、置顶/取消置顶、原文件名/源相对路径、分类编辑、状态/进度/累计时长、笔记与层级目录。目录沿用现有安全 Foliate 打开路径，只缓存有界的只读目录快照；不是新阅读器。
- 全部笔记：检索、四种类型筛选、原文跳转、编辑/删除及分页草稿恢复。草稿仍使用现有草稿服务；不新增原生草稿数据库。
- 统计：复用现有 `readingLog/readingStats`；包含周期/环比、目标、连续阅读、趋势、月历与年度日历、里程碑、逐日书目和排行分页。活跃日门槛为 60 秒，分页前先做全局汇总/筛选；不虚构旧累计时间的每日分布。
- 设置：交互值使用类型/枚举/范围白名单，不把历史迁移归一化器当编辑验证器；服务切换经过原有 Pinia/原生提交恢复屏障。原生尺标校准、重置排版及藏书显示数量均接回既有所有者；密钥与内含凭据的代理字段掩码显示。
- 手册：六篇打包文档由 CommonMark 转为原生控件；离线目录、锚点与受控 HTTPS 外链，不联网抓取正文。

确认置顶/取消置顶后清除既有 `librarySession` 结果顺序，再查询排序；普通阅读器返回仍保留原顺序。分类提交未确认时明确显示“结果未确认”，不称为“未保存”，也不解除原有重放屏障。

导航/显示偏好沿用原有 `librarySession` 所有者，可能有其原有的内存回退；不把该回执称为书库或全局设置的持久提交。书籍/批注仍由现有 SQLite/CAS 接口修改，批量操作逐书报告已确认成功、失败、未执行与未知结果；未知结果不自动重放，关闭界面不代表回滚。

## 设置失败恢复

设置页、非设置管理页工具栏、统计页（查询前及重绘后）和统计目标编辑框均可直接打开同一个原生恢复界面，不通过普通导航进入设置。恢复入口直接查询同一设置所有者及原请求回执，不先等待已失败的保存队列。结果未知或查询不可用时，仅允许继续核对，不产生替代请求或把关闭视为取消。

结果已明确后，由用户选择重新应用保留编辑或丢弃已知内存草稿。决定绑定当前修订及草稿代次，失效后须重新核对；重试按新状态重新构建稀疏 CAS 或原有领域操作，不重放服务商密钥/授权快照。无法安全重建的结构编辑须明确丢弃后重新输入。界面报告只提供路径和数量，不返回保留值。恢复决定不会擅自关闭原输入窗口；关闭并刷新须单独选择。内存草稿不保证跨进程退出恢复。

## 离开与迟到结果

正常返回、换页、刷新、替换对话框与书籍 ID 更新都先确认最新草稿字节。失败保留可访问输入，并阻止正常路由离开。页面可见性由单一 JS 所有者和原生 session/intent/ticket 双侧控制；原生 30 秒单调时钟租约在等待草稿前后都检查，超时不是取消。旧组件卸载不发送无所有者 hide，旧 WebView session 与迟到票据不能覆盖新页面。

Android 13+ 对话框返回通过原生回调走同一屏障，旧版走按键路径；禁止默认取消绕开草稿确认。Activity/process 强制销毁不等于草稿已持久化，不能承诺强制退出时最后一次尚未确认的输入必然保留。
