## 公共图标与原生差异

- 45 个图标名称/别名取自实际 1.4 描边、实心 path 和 marked bookmark，固定路径由已有 AndroidX PathParser 解析后用原生 Canvas Drawable 绘制，不手工近似原轮廓；无新依赖，也不接受用户 SVG。
- 实际生产 XML 函数经 Kotlin/JVM 执行，和旧 SVG 的浏览器栅格比较 45 项无超阈值差异。这证明几何转写，不替代真实原生绘制；后续已完成本轮七页 PixelCopy 窗口取样。
- 底栏使用真实 notes/currently-reading/reading-history/settings 图形，选中描边使用原版 2.25。管理根页标题不再显示误导性的“返回藏书”；返回仅保留在子页面。
- 原版没有现行失败提交的恢复合同，因此保留直接“核对恢复”入口，但图形与刷新区分。所有入口仍走原导航/草稿/恢复屏障，不能为视觉一致删除安全入口。
- 藏书搜索输入框不随结果重建。临时查询协调只合并输入、等待现有请求完成，不创建保存层；正常离开等待待提交的查询状态。进程强制销毁不承诺保存未发送的输入。
