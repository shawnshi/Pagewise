## 关闭的问题与语义差异

- **MLI-PDF-001**：PDF 尚未获得有效位置或打开失败时，退出不再提交默认第 1 页。正常恢复并翻页后才保存实际位置；工具栏与原生 Back 使用同一获确认入口。
- **MLI-PDF-002**：异步初始化续接检查组件存活；迟到 PDF 文档立即关闭、迟到窗口订阅解绑；卸载关闭已接管文档且不再安装观察器。
- **MLI-COMPAT-001**：为声明的 Chrome 89 目标补齐不可枚举的 `Object.hasOwn`，原生实现不覆盖；自有／继承／Symbol／空值行为有回归。
- **UI-FONT-001**：解决内置界面字体在手机主工具栏中的小字与裁切；没有降低尺寸、对比度或裁切断言。
- 旧测试按已采用的主工具栏、内联筛选、紧凑书库卡片和六状态接口更新；SQLite mock 接入真实分类验证函数，仍保留数据往返、失败、撤销与旧库保护断言。
- 书库包测试使用实际新导出标签，下载和点击共同等待；端口动态分配并关闭服务器，不再连接到碰巧占用固定端口的进程。
- 字体资源、许可证与构建容器的详细说明见 [字体方案](font-embedding.md)。字体容器转换不裁剪字形，不修改原书文件。
