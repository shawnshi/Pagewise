### Android 执行停止记录

稳定阻塞 ID：`EINK-S2-ANDROID-SETUP-01`。三次均未产生有效展示回执：

1. `android-red-v1`：`app_process` 以 UID 2000 调用，系统上下文包名为 `android`，触发 SecurityException，退出 137。
2. `android-red-v2`：即使 View 使用自身 shell package context，系统全局上下文仍导致同一异常；退出 137。没有放宽权限或伪造系统身份。
3. `android-red-v3`：改为真正测试 Activity 的方案后，身份预检发现专用模拟器已终止，TCP 5592 拒绝连接。此前 supervisor 设 900 秒上限，回执记录停止原因为 `deadline_or_log_limit`，总计约 908 秒。此调用尚未进入新测试 APK 构建／安装。

**不把上述失败当成预期行为红灯；三次上限后不重启、不补跑第四次。** 新运行器的真实 Activity 路径仅通过离线 Kotlin 编译，尚未走通打包、安装、回执提取或 Android 交互。
