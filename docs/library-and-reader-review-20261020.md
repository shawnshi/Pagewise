日期：2026-10-20。第 2、3 项已实现；第 1 项为源码审查与优化方案，未擅自改动点睛服务、启动恢复目标或阅读排版规则。未读取真实书库/账户配置、调用真实 AI、部署 APK 或改变 BOOX 设置。保留现有未提交改动。

## 1. 点睛、启动页与上下边距

### 结论

优先修复**卡片翻译取消、卡片动态定位、启动状态反馈**。不要直接把阅读上下边距统一减小。PDF 分页安全区存在源码层面的不对称，需要合成几何与真机验证后再补。

当前没有足够证据把这些问题定为 P1；以下“已确认”指代码机制，不代表实机复现。

### PW-R1-DJ-01：卡片关闭后翻译请求继续运行（P2，已确认）

证据：`reader/src/composables/useDianjing.ts:397–426`。`closeCard()` 清空卡片；`translate()` 没有向 `streamDianjing()` 传入取消信号。完成后的目标校验能阻止旧结果回填，却不能停止旧连接或已提交的服务请求。

影响：关闭后重开可以创建新请求，旧请求仍占资源；不能据客户端关闭宣称服务端未计费。

建议：卡片翻译持有独立 AbortController 和代次，关闭、换目标、停用智能点睛或退出阅读时取消；保持去重、目标校验及现有同意/协议规则，不新增自动重试。以延迟的本地替身验证 abort、迟到结果、重复点击和重新打开后的 loading 状态。

### PW-R1-DJ-02：卡片尺寸/原文位置变化后没有完整重新定位（P2，已确认机制；实际溢出待验证）

证据：`useDianjing.ts:358–373` 保存一次原文矩形；`DianjingCard.vue:35–60` 只在挂载及窗口 resize 时定位。译文/错误/展开文字会改变内容（`:98–122`），卡片样式没有 viewport 最大高度和内部滚动约束（`:132–215`）。

影响：长译文、窗口改变和正文重排后可能遮住操作区，或继续指向旧坐标。当前 `place()` 的上下翻转也不能处理卡片本身高于视口的情况。

建议：保留仍有效的 Range，定位时重算宿主坐标；以合并的尺寸观察更新卡片位置，原文卸载就关闭。加入扣除安全区后的最大高度和内容滚动，操作区可达；不要用阅读跳转来追赶卡片，以免改变 CFI。

### PW-R1-DJ-03：点睛部分触控目标偏小（P2，源码值已确认）

`DianjingStatus.vue:65–70` 的状态按钮为 28×28 CSS px；`DianjingCard.vue:228–229` 的窄屏动作按钮仅保证 40px 高，低于项目其他主要阅读操作的 48px 目标。建议扩大外层点击范围、保留小图形本身，并验证工具栏不挤出屏幕。

不能把这个状态点误报成持续旋转加载动画。`DianjingStatus.vue` 使用静态状态点；引擎已有批量/合并绘制与并发限制（`useDianjing.ts:211–212`、`services/dianjing/engine.ts`）。`layer.ts` 主路径采用 CSS Highlight、SVG 覆盖层而不是改写原文字节点。没有证据支持“必然逐 token 重排/闪屏”；实际刷新、残影与缓存重复调度仍需测量。

### PW-R1-BOOT-01：模块启动标记早于首屏可用（P2，静态风险）

- `reader/index.html:24–40`：初始 app 容器为空；兼容性提示依赖 boot 标记。
- `reader/src/main.ts:9–10,26–28`：挂载前已设置 boot 标记。
- `reader/src/router/index.ts:14–28,44–65`：恢复目标需要异步组件和书籍/存储检查。
- `reader/src/App.vue:133–137`：路由视图区缺少独立 pending/error 呈现。

冷启动恢复阅读时，模块、路由或存储迟到/失败可能出现一段空白，而不是“正在打开”。建议区分模块启动、初始路由等待、书籍打开和排版就绪；用真实静态状态与失败重试/返回入口，不造进度百分比。保持现有恢复目标，不自行改成每次回书库。应注入组件/存储延迟与失败验证；原生 splash 退出时序仍未验证。

### PW-R1-INSET-01：PDF 分页与滚动的安全区处理不对称（P2，静态风险）

`PdfReaderView.vue:4867–4880` 将滚动容器和分页容器的适页/适宽 padding 清零，但后续 top/bottom 安全区补偿只给 `.pane-left`，没有给 `.paged-box`。`fitScale():272–288` 直接使用 scroller 的 clientWidth/clientHeight，也没有单独扣除系统安全区。

这说明非零系统栏/手势区条件下存在遗漏风险，但还不能把源码差异等同于已复现遮挡。建议先测分页/滚动、适宽/适页、普通/全屏的实际页矩形，再由唯一层级提供安全区；不能同时加 padding 和扣缩放造成双重留白。覆盖横屏、手势/三键导航及真实 BOOX Insets。

### EPUB 边距不是简单“三次叠加”

`ReaderView.vue:511–519,540–558,583–590,3604` 中：外容器负责系统安全区，renderer margin 负责版心，优化路径只额外补 `page.bottom - page.top` 的底边差值。

非优化路径本就不同：窄屏滚动 12px、其他竖屏滚动 20px；非滚动路径窄屏 36px、其他 48px。沉浸模式隐去页眉页脚文字不等于取消版心边缘，这属于当前产品规则，不是已证实 bug。PDF 重排正文另有上 52px、下 112px 的预留（`PdfReaderView.vue:4793`），不能直接套用 EPUB 数值。

建议明确区分系统安全区、工具栏占位、用户版心边距；若要提供“紧凑/标准/宽松”或独立上/下边距，应在上述扣除之后计算可用矩形，并守住 CFI、最后一行和底部操作区。不在本次直接统一常数或扩大到排版重构。

## 2. 已实现：书架分类栏

当前书架与本地搜索结果共用 `LibraryView.vue`，同一规则覆盖两种状态。

- 移除“管理标签”入口、专属弹窗、全局标签管理的页面处理函数及样式；不删除已有书籍分类/标签数据，不移除后端标签 API 或单书编辑能力。
- 横向按钮显示“全部”、实际有书籍的分类及有内容时的“未分类”，不展示空类别。分类使用现有主分类字段，不擅自把自由主题标签推断为主类别。
- 数量表示整个书库库存；当前关键词和其他条件继续共同过滤结果，所以标签计数与搜索结果数可能不同。
- 切换类别重置页码、选择和结果顺序缓存；最后一本该类别书籍被移除时回到“全部”。返回列表保留有效选择，选中项横向可达。
- 原生按钮支持键盘选择、`aria-pressed`、可见焦点和 48px 高触控目标。选中反馈即时切换，避免反色过渡中间态的对比度下降；横向溢出限于分类栏，不扩宽页面。

## 3. 已实现：排序

| 选项 | 数据与规则 |
|---|---|
| 最近加入（默认） | 原有首次 `addedAt`，新到旧；不使用扫描时间或文件修改时间 |
| 最近阅读 | 有效 `lastReadAt`，新到旧；未读排后，不以加入时间冒充阅读时间 |
| 出版时间 | 原有 `publicationDate`，新到旧；兼容年、年月、完整日期及严格 ISO 日期时间；缺失/无法识别/不存在的日期排后 |

仍保留书名、作者、进度排序及明确的置顶规则。没有有效历史会话时默认最近加入，已有有效排序选择不被强制覆盖。排序状态可恢复；在详情修改出版时间后返回，会刷新出版排序。

年/年月不补造 1 月/1 日；完整时间保留日内时间和时区。无时区的日期时间按固定 UTC 比较，避免因设备时区改变顺序。同值按 ID 稳定排序。归一化缓存会响应同一对象上的出版字段变化；没有存储迁移或在线补齐日期。
