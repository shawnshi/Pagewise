# Note X3 Pro 实机准入

## 当前边界

此阶段只准备上游基线，不是知页阅读器发布。原版 APK 为 LightRead v1.15.0，包名 **`com.yzfly.lightread.debug`**，签名主体为 LightRead Android；它具有 INTERNET 和 REQUEST_INSTALL_PACKAGES 权限，**不满足知页离线目标**。来源、哈希及签名已经校验；没有安装、启动、读取私人书籍或授予未知来源安装权限。

当前 ADB 没有设备；因此启动、WebView 实际渲染、翻页残影、休眠恢复及 SAF 保存都未通过。不要用文件存在、元数据通过或签名通过替代这些行为。

## 1. 连接及只读元数据检查

在目标平板上由用户启用 USB 调试，使用数据线连接并在设备上接受本机的调试授权；不要绕过设备授权。然后在项目目录运行：

```powershell
pwsh -NoProfile -File scripts/Test-NoteX3Pro.ps1
# 多台设备时显式指定目标；脚本不把序列号写入报告。
pwsh -NoProfile -File scripts/Test-NoteX3Pro.ps1 -Serial '<目标序列号>'
```

脚本仅执行 `adb devices`、有限 getprop 和 WebView 服务元数据查询，不安装/启动/卸载应用、不清除数据、不扫描书籍和应用列表、不截图。

退出码：0 = 仅设备元数据通过；2 = 无设备/未授权/目标不匹配/WebView 未确认；1 = 工具或命令实际失败。型号必须明确为 Note X3 Pro；Android 12 对应 API 31 或 32，不能把本机 Android SDK 平台版本当作设备系统版本。

元数据通过后，实际阅读准入仍未通过。原版首次安装/运行应由用户在目标设备上观察；若同包名应用已存在，停止，不覆盖、不卸载、不清数据。不要授予更新安装权限，不开启 AI、统计/同步等在线功能；可先在飞行模式评估基本 EPUB 阅读。原版在线能力尚未完成独立流量审计。

## 2. 无私人数据的样书

`artifacts/fixtures/` 已生成 4 本合成、无 DRM 的 EPUB：

| 文件 | 元数据声明 | 后续知页语言预设预期 |
|---|---|---|
| zh.epub | zh-CN | 中文 |
| en.epub | en | 英文 |
| und.epub | und | 不自动套用 |
| mixed.epub | zh-CN + en | 不自动套用 |

每本有两个章节、稳定段落锚点及足够的翻页文本。它们仅验证基本路径，不代表真实复杂 EPUB 的兼容性，也不包含手写、图片、脚注等专项样本。原版 LightRead 尚未实现知页的自动语言预设，不能把上表当作原版应该通过的功能。

如需另建一套合成样书，可运行 `scripts/New-TestEpubs.ps1 -OutputDirectory '<全新输出目录>'`；脚本拒绝覆盖已有样书。不得为了测试自动扫描或上传个人藏书。

## 3. 原版准入观察表（均待实机）

- 冷启动无白屏/崩溃，本地导入两本中英文合成 EPUB。
- 正文、目录、中文标点、英文字体和章节跳转可用。
- 连续翻页及字号调整可接受；与 NeoReader 对照记录残影和响应，不预设未经测量的数值。
- 更改字号后仍定位到同一段内容。
- 返回书库、结束进程、重新打开与休眠唤醒后定位正确。
- 书签/文字批注重开后存在，且绑定原内容。
- 飞行模式可以重新启动并打开本地书籍；此项不是对原版无联网能力的证明。
- 备份必须真正保存为文件，重新导入到隔离测试环境后才能计为恢复成功；取消/失败不能出现成功提示。不要清除已有应用数据来制造“新环境”。

任何关键项失败，保留错误与对应版本证据后停在该项，不用延时、最近访问记录或成功提示代替实际结果。

## 4. 后续知页专用版本门槛

- 独立身份：计划正式包 `io.pagewise.reader`，调试包 `io.pagewise.reader.debug`；不复用旧 NeoReader 控制器或 LightRead 包名。
- Android 最终打包清单无 INTERNET、REQUEST_INSTALL_PACKAGES 和全盘/旧式存储权限；不能只检查源模板。
- 不注册网络/更新/外部应用打开命令，不导入上游启动统计/同步链。EPUB 脚本及外部导航关闭；远程图片/字体/连接均阻断，本地资源仍能显示。
- 文档导出使用受限原生 SAF 接口，处理取消、权限/I/O 失败与 Activity 生命周期；关闭实际输出流后才报告保存。
- 原生签名公钥指纹需要固定；不读取或复用未知签名私钥，不把 debug 当正式升级通道。

未来可用 `scripts/Test-ReaderApk.ps1 -Mode Pagewise -ApkPath '<实际APK>' -CertificateSha256 '<事先确认的公钥指纹>'` 做部分静态检查，但这个脚本不证明运行时离线、原生保存可靠或已完成设备验收。
