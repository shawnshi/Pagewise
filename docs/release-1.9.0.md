# 知页 1.9.0：功能与验证范围

日期：2026-10-25。Android versionName 为 `1.9.0`，versionCode 为 `1009000`。

| 变体 | 应用显示名 | 包名 |
|---|---|---|
| Release | 知页 | `io.pagewise.reader` |
| Debug | 知页 1.9.0 测试版 | `io.pagewise.reader.debug` |

两版使用独立数据目录，不自动复制书库或设置。此源码同步不包含 APK、签名材料、设备日志或私人书库，也没有创建 GitHub Release。

## 代码整合

- 原生管理与存储：七个管理入口采用 Android Views；canonical 数据库准入、设置恢复、导入任务和未知结果不重放边界保持独立职责。
- 生命周期：针对 Tauri Android 2.11.5 的项目内固定版本兼容 overlay，核对上游摘要后生成本地模块；不修改全局 Cargo registry，也不升级 SDK。见 [overlay 说明](../reader/src-tauri/android-sdk/tauri-2.11.5/README.md)。
- AI 简介：最小书目信息分享、可编辑预览、显式确认和 description CAS；不发送原简介、正文或批注，不把生成成功等同于保存成功。
- 本地推荐：正在阅读、书籍详情、书末三个入口，按书目、分类等本地信息排序。可选 AI 需单独同意元数据分享；没有采用外部 embedding，也不保证推荐质量已完成真实馆藏评估。
- 统计与设置：概览/趋势/年历、八组设置目录、有界弹窗和灰阶呈现；不改变统计口径、canonical 设置值、CAS 或未知结果恢复规则。
- 测试：加入简介、推荐、数据库准入、阅读器返回、原生布局与窗口就绪同步器的定向用例及合成 fixture。

版本整合沿用既有 npm/Cargo 依赖图；没有为本轮发布升级依赖、增加字体下载、迁移 Compose 或替换正文阅读器。

- Vue/TypeScript 类型检查和实际 Vite `build()` 通过。

- 进行安装前独立只读审查；审查通过不替代设备验证。

### 设备与限定功能

在 BOOX Note X3 Pro / Android API 32 上：

- 两包同签名覆盖安装；安装 APK 与构建产物摘要一致，UID、数据目录身份与首次安装时间保持。未卸载或清数据。
- 分别检查藏书、正在阅读、全部笔记、阅读统计、设置五个主页面；触发统计三标签与三个设置目录入口，确认原生关于内容渲染。
- Debug 用自有合成 EPUB 检查正文可见、两个目录数据项、翻页改变实时 CFI，以及正常工具栏返回保存最后可见 CFI、释放 Reader owner。
- 合成测试书及对应文件已移除。测试前后 Debug 原有书目 ID 摘要、批注数量一致，数据库完整性检查正常。该次基线是安装后、合成测试前的基线，不是完整安装前后数据库逐字节比较。

统计/设置原生 P1 的既有限定结果为 **27/27**；其余五个预定配置未执行，不能把另一字体/分辨率的实机检查当成替代。

## 数据保护与恢复限制

- 没有完整 Release 物理数据库备份、全字段对照或完整库 integrity 验证。安装身份保持不能证明全部数据不变。
- Debug 的安装前 canonical DB、存在的 sidecar 与 locator 字节副本，不等同于整馆藏备份。
- 旧代码 APK 已保留并校验同版本恢复路径，但没有执行回滚演练；代码恢复包不是数据库恢复保证。
- 正常阅读/导航可能写入 session、进度和时长；不把设备验证描述为完全只读。
- BOOX 可能自动冻结后台应用；本轮使用官方桌面图标正常启动，没有修改全局冻结策略，不承诺后台免冻结。
