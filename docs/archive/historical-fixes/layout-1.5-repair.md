# 1.5 原生界面布局修复候选

状态：布局修复已通过最终独立复审，两版正常 APK 已安装并检查启动。七页隔离合成内容、同页缩放、底栏点击和恢复入口已核对；软键盘显示未确认，不宣称全部交互、真实书库或 EPD 已验收。

## 参考基准

使用仓库提交 `b529185`（1.4.0）的 App、全局样式与七页 Vue 源码作参照。实际结构是底部五栏导航（CSS 类名虽叫 sidebar）、58×78 封面列表、1200 最大内容宽度与 24 页面内边距，不能根据类名误做成侧栏或网格。最初口头判断已按实际源码更正。

保留七页 Android 原生 Views 和 EPUB/PDF 正文实现；不通过回落旧 WebView 管理页规避问题，不改变设置/统计/书库/草稿/导入/TTS/EPD 所有者。

## 本轮布局变化

- 恢复藏书、正在阅读、笔记、统计、设置五个底部导航入口；详情归藏书，手册归设置，手册仍可通过菜单访问。所有切换仍走原有导航、草稿与提交恢复屏障。
- 顶栏使用有完整无障碍名称的 48dp 图形按钮，避免返回、标题、恢复和刷新长文字互相挤压。直接恢复入口保留，不经过失败的普通导航屏障。
- 内容居中并限制最大宽度；操作按钮按测量宽度自动换行。只有类别和阅读分组明确保留横向标签条，不将所有操作藏在横向滚动行中。
- 书目采用 1.4 封面比例、标题/作者/状态分层和可见“更多”入口；详情封面与身份信息在宽窗并排、窄窗上下堆叠，元数据按实测宽度分列。书目操作方向和详情列数在每次测量时更新，不通过刷新或重建业务状态实现缩放；笔记使用一致卡片边界与留白。
- 设置保留原有分组与业务表单，使用标签/值成对的响应式行，窄屏或大字时上下堆叠；常见枚举与高级筛选名称使用可读标签，查询值和保存内容不变。
- 字体继续遵循系统缩放；底栏文字允许换行，触摸区域至少 48dp。图形状态同时有文字/选中标记，焦点和按压状态可见，颜色对按实际中性色值复算。
- 原生覆盖层拦截空白处点击，显示期间暂时隐藏被遮挡内容的无障碍节点，返回阅读器时恢复原值，避免交互穿透和两个导航树混杂。

## 证据与限制

- 实际 Android `compileUniversalDebugKotlin` 通过，未执行本轮 Rust 重编译；业务层和前端正文没有变更。
- 生产几何函数在多个可用宽度与 1×/2×/3× 合成文字尺寸下验证边界、换行与非重叠；文字/背景及控件边界对比度检查通过。这些不是 Android 字体排版或完整无障碍认证。
- 受影响的设置恢复、受保护注册表、详情/置顶源码绑定、草稿/可见性协调器和 Android 准备流程已执行对应回归；较早失败日志保留。修正了测试错误假设（1.4 导航不是 bottom:0 定位）、JVM 调用参数，以及格式化后仍使用单行正则的旧源码检查；未通过改变业务断言掩盖失败。
- 草稿/可见性宿主编译补入实际新增的展示组件依赖，没有替换生产协调器。继续保留此前 SQLite PRAGMA 启动修复和用户未提交改动。
