## 实施范围

- Android Back：WebView 创建后注册回调，避免 Tauri 默认回调抢先消费；阅读器与 PDF 显式持有 Back owner。保存中阻止重复返回，保存失败不导航，卸载后旧异步结果不得影响新页面。
- 阅读工具栏默认顺序：目录、搜索、书签、批注、阅读助手、朗读、排版；更多菜单移除重复入口。窄屏采用换行布局，保留可见文字及至少 48 CSS px 命中区。CSS px 不等于实体毫米验收。
- PDF 没有既有实现的书签、阅读助手入口明确禁用，不伪装为可用；朗读保持既有实际处理。
- 阅读状态顺序：未标记、想读、在读、暂缓、已读、弃读。对应 ID 为 `unmarked`、`wanted`、`reading`、`paused`、`finished`、`abandoned`。
- 旧 `unread` 保守映射为 `unmarked`，不推断为想读；旧 paused/finished/reading ID 保留。明确未标记覆盖 lastReadAt 回退；缺失字段继续保留旧记录兼容行为。进度不推断想读、已读或弃读。
- 详情、批量操作、筛选与会话恢复、SQLite/IndexedDB 及新旧 manifest/OKF 备份均适配；阅读状态仍不作为新内容标签生成依据。旧分类解析边界保持不变，即使旧标签与新增状态同名也原样读取，不因枚举扩展阻断书库、打开或备份。
