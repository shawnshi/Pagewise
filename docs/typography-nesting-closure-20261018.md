## 新发现的持久性风险：PW-R4-RESTART-01

立即保存纯正文选项并强停进程后，该新选项曾未恢复。进程退出元数据确认实际执行了强停；重新载入后的内存与 localStorage 均为原有单书配置，旧的32px／3%等设置未丢失。这是新增的真实残留风险，不能被后续通过覆盖。

另一次验证在保存后观察到 localStorage 含该选项，等待 **7008ms** 存储稳定窗口，再实际强停／重启，纯正文选项和原逻辑字符位置恢复，随后原样还原测试前偏好。证据为 `native-publication-restart-stable.json`、`native-restart-stable-trace.json`；等待时间是这次测试条件，不是产品保证，也不是运行时修复。

本轮没有改动存储架构；同步 API 返回不等于底层持久落盘，具体原因仍需独立排查。不能宣称突然终止／断电下不丢最近设置。该风险与嵌套分类问题分开处理。
