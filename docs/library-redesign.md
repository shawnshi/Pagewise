# 书库页面修改与验收

## 范围

本次按 P0 → P1 → P2 实施书库异常恢复、筛选整合、信息去噪、阅读返回排序和分页调整。不新增依赖，不恢复任意文件导入，不改源文件，不删除或合并已有书籍记录。

用户另行授权将必要的既有文件夹、结构化分类及阅读状态依赖纳入主线。该依赖包含可选分类字段的幂等迁移、分类修订冲突保护，以及备份 v3：旧 JSON v1/v2 和 OKF 仍可导入；包含结构化分类的 JSON 兼容清单导出为 v3，旧客户端不能将 v3 当作 v2 使用。主线候选单独验证，不夹带字体、排版、环境配置或氛围功能退休等无关改动。

## 行为

- 文件缺失和文件夹权限失效分别显示；阅读状态、进度不被文件状态覆盖。列表阅读按钮分流为重新定位或重新授权，详情仍能查看笔记。直接访问阅读路由也检查文件状态。
- 文件夹路径、说明、更换和扫描入口归设置；首页仅显示短异常提示。部分扫描失败也显示异常，不报告无条件成功。
- 重新定位只列出当前已授权监测文件夹中的同格式候选；用户必须确认同作品、同版本。改选文件会同步清除旧勾选，必须针对新候选重新确认。解析失败、目录不完整、源文件或文件夹变化、并发扫描均不能替换原文件引用。
- 关联成功仅修改原记录的文件引用、文件名和可用性，保留 ID、手工元数据、分类、进度、阅读位置和笔记。同一文件已有其他条目时，两个记录及笔记均保留；扫描同步维护这些关联，不自动去重。
- 筛选统一为页面内可折叠区域：主分类、主题标签、状态、语言、格式；低频分类条件、特征和历史标签在更多条件中。修改草稿后点击应用；主题组支持全含或任一匹配。查看全库不可用书籍时暂存原筛选，可恢复，并保留跨详情导航的恢复信息。
- 条目展示书名、阅读状态和进度、作者（存在时）、格式及最多两个主题标签。不显示缺失元数据占位，不把缺失作者当成佚名。完整分类及标签仍保存在详情并可筛选。
- 续读条仅保留书名、进度和动作。完整列表仍包含该书。
- 当前浏览顺序冻结；扫描发现的新书追加到快照，已有书不因后台更新跳动。阅读器返回后重新查询、按所选排序重建顺序并定位该书；不会强改用户排序。显式置顶和取消置顶可立即更新排序。
- 单页只显示结果数；多页提供翻页和跳页。每页数量移至设置的书库显示区域。筛选后修正页码；无结果提供清空条件入口。
- 复用既有电子墨水模式，选中状态结合边框、字重和勾选；保留普通屏幕主题，不改变阅读器全局主题。
